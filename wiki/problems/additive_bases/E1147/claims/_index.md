# problems/additive_bases/E1147/claims

[[problems/additive_bases/E1147/_index|..]]

[[problems/additive_bases/E1147/claims/2015_04_09_konieczny|2015_04_09_konieczny]]: Konieczny (2016) proves that for almost every $\alpha>0$, and explicitly for
$\alpha=\sqrt2$, the set of $n$ for which $\alpha n^2$ lies within $1/\log n$
of an integer is not an additive basis of order two. So the answer is no.
