# problems/distance_problems/E1082/claims

[[problems/distance_problems/E1082/_index|..]]

[[problems/distance_problems/E1082/claims/1963_02_01_altman|1963_02_01_altman]]: In a refereed paper (Amer. Math. Monthly, 1963), Altman proves that every
convex $n$-gon determines at least $\lfloor n/2\rfloor$ distinct distances. So
the first question holds for every set in convex position.

[[problems/distance_problems/E1082/claims/1997_10_01_erdos_fishburn|1997_10_01_erdos_fishburn]]: Erdős and Fishburn published, with credit to Harborth, eight points in the
plane, no three on a line, from each of which only three distinct distances
are seen. So the second question has a negative answer.

[[problems/distance_problems/E1082/claims/2026_02_25_deepmind|2026_02_25_deepmind]]: A DeepMind prover agent found a Lean 4 proof, from the formal-conjectures
statement, that eight points with no three on a line need not contain a point
seeing four distinct distances. So the answer to the second question is no.

[[problems/distance_problems/E1082/claims/2026_08_31_sallerk|2026_08_31_sallerk]]: An unreviewed, dated note linked from the erdosproblems.com thread deduces
from the published maximum planar $k$-distance sets that the first question
holds for every $n\le15$.
