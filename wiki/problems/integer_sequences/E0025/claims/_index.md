# problems/integer_sequences/E0025/claims

[[problems/integer_sequences/E0025/_index|..]]

[[problems/integer_sequences/E0025/claims/2026_03_19_chojecki|2026_03_19_chojecki]]: Chojecki's unrefereed note, posted in the site's thread, proves that the
sifted set of Problem 25 has natural, hence logarithmic, density when the
reciprocals of the moduli are summable or the moduli are pairwise coprime.

[[problems/integer_sequences/E0025/claims/2026_03_19_chojecki_conditional|2026_03_19_chojecki_conditional]]: Chojecki's note deduces that the logarithmic density of the sifted set of
Problem 25 exists and equals the limit of the truncation densities. The
deduction rests on an unproved uniform harmonic estimate for the set's
first-kill quotient sieves.
