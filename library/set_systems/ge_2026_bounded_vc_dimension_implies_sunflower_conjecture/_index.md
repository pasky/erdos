# Bounded VC-dimension implies the Erdos–Rado sunflower conjecture

[[set_systems/_index|..]]

***

Ge, Gennian, Jian Wang, Zixiang Xu, and Xiaochen Zhao, *Bounded VC-dimension implies the Erdős–Rado sunflower conjecture*, arXiv:2609.18995v1 (2026).

The abstract asserts the sunflower conjecture for uniform set families of bounded VC dimension. The bound is exponential in the uniformity for fixed sunflower size and VC dimension. The VC-dimension restriction remains a hypothesis, so the assertion does not settle the unrestricted catalog question.
