# Analysis

[[problems/_index|..]]

[[problems/analysis/E0120/_index|E0120/]]: Asks whether, for every infinite set
$A$ of reals, some set of positive measure contains no affine copy $aA+b$ with
$a\neq0$; open.

[[problems/analysis/E0225/_index|E0225/]]: Asks whether a trigonometric
polynomial $f$ with all roots real and maximum modulus $1$ satisfies
$\int_0^{2\pi}|f(\theta)|\,\mathrm{d}\theta\le4$; proved.

[[problems/analysis/E0226/_index|E0226/]]: Asks whether some non-linear entire
function $f$ has $f(x)$ rational exactly when the real number $x$ is rational;
proved.

[[problems/analysis/E0227/_index|E0227/]]: Asks whether, for a non-polynomial
entire function $f=\sum a_nz^n$, the limit as $r\to\infty$ of $\max_n\lvert
a_nr^n\rvert/\max_{\lvert z\rvert=r}\lvert f(z)\rvert$, when it exists, must be
$0$; disproved.

[[problems/analysis/E0229/_index|E0229/]]: Asks whether, for any sets
$S_1,S_2,\ldots$ of complex numbers with no finite limit point, some
transcendental entire function $f$ has, for each $n$, a derivative $f^{(k_n)}$
vanishing on all of $S_n$; proved.

[[problems/analysis/E0256/_index|E0256/]]: Asks for estimates of the largest
$f(n)$ such that $\max_{\lvert z\rvert=1}\lvert\prod_i(1-z^{a_i})\rvert\geq
f(n)$ for every choice of $n$ integers $1\leq a_1\leq\cdots\leq a_n$; open.

[[problems/analysis/E0395/_index|E0395/]]: Asks whether, for unit complex
numbers $z_1,\ldots,z_n$ and random signs $\epsilon_i$, the sum
$\sum\epsilon_iz_i$ has modulus at most $\sqrt{2}$ with probability $\gg 1/n$;
proved. Erdős asked it with radius $1$, which fails for every even $n$.

[[problems/analysis/E0498/_index|E0498/]]: Asks whether at most
$\binom{n}{\lfloor n/2\rfloor}$ of the signed sums $\sum\epsilon_iz_i$ of $n$
complex numbers with $\lvert z_i\rvert\geq 1$ can lie in one open disc of radius
$1$; proved.

[[problems/analysis/E0510/_index|E0510/]]: Asks whether every set $A$ of $N$
positive integers has some $\theta$ with $\sum_{n\in A}\cos(n\theta)<-cN^{1/2}$,
for an absolute constant $c>0$; open. The site's wording, over all integers,
fails for sets containing $0$.

[[problems/analysis/E0511/_index|E0511/]]: Asks whether, for each $c>1$, the set
where a monic polynomial has modulus below $1$ has $O_c(1)$ connected components
of diameter above $c$, whatever the degree; disproved.

[[problems/analysis/E0512/_index|E0512/]]: Asks whether the exponential sum over
any set $A$ of $N$ integers has mean absolute value $\int_0^1\lvert\sum_{n\in
A}e(n\theta)\rvert\,\mathrm{d}\theta\gg\log N$; proved.

[[problems/analysis/E0513/_index|E0513/]]: Asks for the greatest possible value
of $\liminf_{r\to\infty}\max_n\lvert a_nr^n\rvert/\max_{\lvert z\rvert=r}\lvert
f(z)\rvert$ over transcendental entire functions $f=\sum a_nz^n$; open.

[[problems/analysis/E0514/_index|E0514/]]: Asks whether every transcendental
entire function $f$ has a path to infinity on which $\lvert
f(z)/z^n\rvert\to\infty$ for all $n$, how long it must be, and whether $\lvert
f\rvert$ can outgrow a fixed function of its maximum modulus. The first part is
proved, and pending claims answer the rest.

[[problems/analysis/E0515/_index|E0515/]]: Asks whether every non-polynomial
entire function $f$ has a locally rectifiable path $C$ to infinity with
$\int_C\lvert f(z)\rvert^{-\lambda}\,\mathrm{d}z$ finite for every $\lambda>0$;
proved.

[[problems/analysis/E0516/_index|E0516/]]: Asks whether every entire function
$\sum a_kz^{n_k}$ of finite order with $n_k/k\to\infty$ has $\limsup\log
m(r)/\log M(r)=1$, where $m(r)$ and $M(r)$ are its minimum and maximum modulus
on $\lvert z\rvert=r$; proved.

[[problems/analysis/E0517/_index|E0517/]]: Asks whether an entire power series
$\sum a_kz^{n_k}$ with $n_k/k\to\infty$ must take every complex value infinitely
often; open.

[[problems/analysis/E0519/_index|E0519/]]: Asks whether complex numbers
$z_1,\ldots,z_n$ with $z_1=1$ always satisfy $\max_{1\leq k\leq
n}\lvert\sum_iz_i^k\rvert>c$ for an absolute constant $c>0$; proved.

[[problems/analysis/E0527/_index|E0527/]]: Asks whether, for real $a_n$ with
$\sum\lvert a_n\rvert^2=\infty$ and $\lvert a_n\rvert=o(1/\sqrt{n})$, almost
every choice of signs $\epsilon_n=\pm1$ makes $\sum\epsilon_na_nz^n$ converge at
some $z$ on the unit circle; proved.

[[problems/analysis/E0671/_index|E0671/]]: Asks whether some nodes in $[-1,1]$
make the Lagrange interpolants of every continuous $f$ converge to $f$ at some
$x$ where the Lebesgue function is unbounded, and whether this can happen when
it is unbounded at every $x$. Pending claims answer both yes; the site lists it
as OPEN.

[[problems/analysis/E0906/_index|E0906/]]: Asks whether there is a
transcendental entire function $f$ such that, for every infinite sequence
$n_1<n_2<\cdots$, the zeros of the derivatives $f^{(n_k)}$ together are dense in
the plane. Pending claims construct one; the site lists it as OPEN.

[[problems/analysis/E0907/_index|E0907/]]: Asks whether a real function $f$ with
every difference $f(x+h)-f(x)$ continuous must be the sum of a continuous
function and an additive one; proved.

[[problems/analysis/E0908/_index|E0908/]]: Asks whether a real function $f$ with
every difference $f(x+h)-f(x)$ measurable is the sum of a measurable function,
an additive function and a function $r$ with $r(x+h)=r(x)$ for each $h$ and
almost all $x$; proved. The site's wording asks for a continuous first term.

[[problems/analysis/E0909/_index|E0909/]]: Asks whether, for each $n\geq 2$,
there is a space $S$ of dimension $n$ whose square $S^2$ also has dimension $n$;
proved.

[[problems/analysis/E0910/_index|E0910/]]: Asks whether every connected set in
$\mathbb{R}^n$ has a connected subset that is neither a point nor homeomorphic
to the whole set. This page treats it as open, though the site labels it
DISPROVED.

[[problems/analysis/E0967/_index|E0967/]]: Asks whether
$1+\sum_ka_k^{-(1+it)}\neq 0$ for every real $t$ whenever $1<a_1<a_2<\cdots$ are
integers with $\sum 1/a_k<\infty$; disproved.

[[problems/analysis/E0973/_index|E0973/]]: Asks whether there is $C>1$ such
that, for every $n\geq 2$, some complex $z_1=1,z_2,\ldots,z_n$ with $\lvert
z_i\rvert\geq 1$ satisfy $\lvert\sum_iz_i^k\rvert<C^{-n}$ for all $2\leq k\leq
n+1$. Pending claims answer no; the site lists it as OPEN.

[[problems/analysis/E0974/_index|E0974/]]: Asks whether complex numbers
$z_1=1,z_2,\ldots,z_n$ whose power sums vanish on infinitely many runs of $n-1$
consecutive indices must essentially be the $n$th roots of unity, in the precise
form of Tijdeman's classification; proved.

[[problems/analysis/E0990/_index|E0990/]]: Asks whether the arguments of a
polynomial's roots are equidistributed with error $\ll(n\log M)^{1/2}$, where
$n$ is the number of nonzero coefficients and $M$ is a ratio of coefficient
sizes; disproved.

[[problems/analysis/E0996/_index|E0996/]]: Asks whether, for some absolute $C>0$
and every lacunary $n_k$, each $f\in L^2([0,1])$ whose Fourier partial sums
satisfy $\|f-f_n\|_2\ll(\log\log\log n)^{-C}$ has averages of $f(\{\alpha
n_k\})$ tending to $\int_0^1f$ for almost all $\alpha$. Pending claims answer
no; the site lists it as OPEN.

[[problems/analysis/E1038/_index|E1038/]]: Asks for the infimum and supremum of
the measure of $\{x\in\mathbb{R}:\lvert f(x)\rvert<1\}$ over non-constant monic
real polynomials $f$ with all roots in $[-1,1]$. The supremum is settled, and
pending claims give the infimum.

[[problems/analysis/E1040/_index|E1040/]]: Asks whether the least area $\mu(F)$
of $\{z:\lvert f(z)\rvert<1\}$, over monic $f$ with roots in a closed infinite
$F\subseteq\mathbb{C}$, is determined by the transfinite diameter of $F$, and
whether $\mu(F)=0$ when that diameter is $\geq 1$. Pending claims answer both.

[[problems/analysis/E1042/_index|E1042/]]: Asks whether $\{z:\lvert
f(z)\rvert<1\}$ can have $n$ components for monic $f$ of degree $n$ with roots
in a closed $F\subset\mathbb{C}$ of transfinite diameter $1$ in no closed disc
of radius $1$, and whether it has at most $(1-c)n$, with $c=c(F)>0$, when the
diameter is below $1$; proved.

[[problems/analysis/E1043/_index|E1043/]]: Asks whether every monic non-constant
polynomial $f\in\mathbb{C}[x]$ has a line onto which $\{z:|f(z)|\le1\}$ projects
to a set of measure at most $2$; disproved.

[[problems/analysis/E1044/_index|E1044/]]: Asks for the infimum of $\Lambda(f)$,
the largest boundary length of a connected component of $\{z:|f(z)|<1\}$, over
polynomials $f(z)=\prod_{i=1}^n(z-z_i)$ with every $|z_i|\le1$; solved.

[[problems/analysis/E1045/_index|E1045/]]: Asks for the maximum of $\prod_{i\neq
j}|z_i-z_j|$ over $z_1,\ldots,z_n\in\mathbb{C}$ with all $|z_i-z_j|\le2$, and
whether a regular polygon attains it; open.

[[problems/analysis/E1046/_index|E1046/]]: Asks whether, for a monic polynomial
$f\in\mathbb{C}[x]$, the set $\{z:|f(z)|<1\}$ lies in a disc of radius $2$
whenever it is connected; proved.

[[problems/analysis/E1047/_index|E1047/]]: Asks whether, for a monic polynomial
$f$ with $m$ distinct roots and $c>0$ small enough that $\{z:|f(z)|\le c\}$ has
$m$ connected components, all these components must be convex; disproved.

[[problems/analysis/E1048/_index|E1048/]]: Asks whether, for a monic polynomial
$f$ with all roots in $|z|\le r$ for some $r<2$, the set $\{z:|f(z)|<1\}$ must
have a connected component of diameter $>2-r$; disproved.

[[problems/analysis/E1115/_index|E1115/]]: Asks how slowly the length $\ell(r)$
in $|z|<r$ of a path on which an entire $f$ of finite order tends to $\infty$
can grow, and whether $\ell(r)\ll r$ is possible; disproved at every finite
order, even for $f$ growing arbitrarily close to the $(\log r)^2$ threshold that
guarantees radial paths.

[[problems/analysis/E1116/_index|E1116/]]: Asks whether some meromorphic (or
entire) $f$ has $\limsup_{r\to\infty}n(r,a)/n(r,b)=\infty$ for every $a\neq b$,
where $n(r,a)$ counts the roots of $f(z)=a$ in $|z|<r$; proved.

[[problems/analysis/E1117/_index|E1117/]]: Asks whether $\limsup\nu(r)=\infty$
is possible, and whether $\liminf\nu(r)=\infty$ is, where $\nu(r)$ counts the
points of $|z|=r$ at which a non-monomial entire function attains its maximum
modulus; both parts have pending claims.

[[problems/analysis/E1118/_index|E1118/]]: Asks for the minimum growth rate of a
non-constant entire $f$ for which $E(c)=\{z:|f(z)|>c\}$ has finite measure, and
whether some $c'<c$ must then also give finite measure; solved.

[[problems/analysis/E1120/_index|E1120/]]: Asks for the shortest length of a
path from $0$ to $|z|=1$ inside $\{z:|f(z)|\le1\}$, where $f$ is a monic
polynomial of degree $n$ with all roots in $|z|\le1$; open.

[[problems/analysis/E1125/_index|E1125/]]: Asks whether every
$f:\mathbb{R}\to\mathbb{R}$ with $2f(x)\le f(x+h)+f(x+2h)$ for all
$x\in\mathbb{R}$ and $h>0$ must be monotonic; proved.

[[problems/analysis/E1126/_index|E1126/]]: Asks whether a function $f$ with
$f(x+y)=f(x)+f(y)$ for almost all $x,y\in\mathbb{R}$ must agree almost
everywhere with some $g$ satisfying $g(x+y)=g(x)+g(y)$ for all $x,y$; proved.

[[problems/analysis/E1154/_index|E1154/]]: Asks whether, for every
$\alpha\in[0,1]$, some ring or field in $\mathbb{R}$ has Hausdorff dimension
$\alpha$. Mauldin's theorem gives yes under the continuum hypothesis, so ZFC
cannot refute the existence, but whether ZFC proves it is open.

[[problems/analysis/E1164/_index|E1164/]]: Asks whether $\log
R_n\asymp\sqrt{\log n}$ in probability, where $R_n$ is the radius of the largest
origin-centered disc a planar simple random walk covers within $n$ steps. The
site's "almost every" wording is corrected, and the result is proved by Révész
and by Dembo–Peres–Rosen–Zeitouni.

[[problems/analysis/E1165/_index|E1165/]]: Asks, for each integer $r\ge3$, for
the probability that a planar simple random walk has exactly $r$ sites tied for
the maximum local time infinitely often; solved.

[[problems/analysis/E1166/_index|E1166/]]: Asks whether, almost surely, the
number of sites that are favorite at some time up to $n$ in a planar simple
random walk is at most $(\log n)^{O(1)}$ for all large $n$; a proof is claimed
but still pending.

[[problems/analysis/E1195/_index|E1195/]]: Asks how fast $|S\cap(0,x)|$ can tend
to infinity for a set $S\subset\mathbb{R}$ of infinite measure in which $a/b$ is
never an integer for distinct $a,b\in S$; solved.

[[problems/analysis/E1197/_index|E1197/]]: Asks whether, for every
$E\subset(0,\infty)$ of positive measure and almost every $x>0$, each large
enough integer $n$ has $nx\in r\cdot E$ for some integer $r\ge1$; disproved.

[[problems/analysis/E1215/_index|E1215/]]: Asks whether some constant $C$
ensures that every nonconstant polynomial $P$ with $P(0)=1$ and all roots on the
unit circle has a path of length at most $C$ from $0$ to the unit circle lying
in $\{z:|P(z)|<1\}$ except at $0$; disproved.

[[problems/analysis/E1221/_index|E1221/]]: Asks whether $\Lambda_r-r$,
$r-\lambda_r$ and $r(\mu_r-1)$ tend to infinity for the de Bruijn–Erdős
constants of the largest and smallest sums of $r$ consecutive gaps on the circle
and their ratio; open, though an unrefereed, unreviewed 2026 preprint claims all
three for distinct points.
