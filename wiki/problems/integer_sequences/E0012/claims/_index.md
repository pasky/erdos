# problems/integer_sequences/E0012/claims

[[problems/integer_sequences/E0012/_index|..]]

[[problems/integer_sequences/E0012/claims/2001_04_01_schoen|2001_04_01_schoen]]: Schoen's refereed 2001 theorem in J. Combin. Theory Ser. A shows that a
pairwise coprime set with property P has fewer than $2N^{2/3}$ elements up to
$N$ for infinitely many $N$. This answers the second question yes for pairwise
coprime sets.

[[problems/integer_sequences/E0012/claims/2004_10_08_baier|2004_10_08_baier]]: Baier's refereed 2004 theorem in Integers shows that a pairwise coprime set
with property P has fewer than $(3+\varepsilon)N^{2/3}/\log N$ elements up to
$N$ for infinitely many $N$. This sharpens Schoen's bound for the second
question.

[[problems/integer_sequences/E0012/claims/2026_04_03_deepmind|2026_04_03_deepmind]]: DeepMind's construction, first posted 3 April 2026, gives an infinite set with
property P whose counting function is at least $N^{1-\varepsilon}$ for every
$\varepsilon$. The site credits it with answering the first question yes and
the second no.

[[problems/integer_sequences/E0012/claims/2026_04_07_sothanaphan|2026_04_07_sothanaphan]]: Sothanaphan's note, produced with GPT-5.4 Thinking and posted in the thread,
builds sets with property P from narrow tagged blocks. By its own construction
it answers the first question yes and the second no, and it is not refereed.

[[problems/integer_sequences/E0012/claims/2026_07_30_ndikum_ndikum|2026_07_30_ndikum_ndikum]]: A partial proof claim of 30 July 2026 by Philip Ndikum and Serge Ndikum, made
with Libertas Superintelligence, asserts that every good set has a convergent
reciprocal sum. Its Lean development rests on a declared axiom that is false.
