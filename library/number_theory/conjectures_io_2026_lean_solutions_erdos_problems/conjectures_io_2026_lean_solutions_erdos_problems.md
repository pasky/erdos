**Source type.** Web records on Conjectures.io, each holding one Lean source
file submitted against a Conjectures.io task. The record page is
`https://conjectures.io/results/<record id>`, its solution page appends
`/solution` and the Lean file itself appends `/solution/download`. No paper or
write-up is part of this source.

**Terms.** Conjectures.io's terms of service
(<https://conjectures.io/terms>, effective 13 August 2026, read 2026-10-14)
state that a submitter keeps ownership of the material submitted and grants
Conjectures.io "a worldwide, non-exclusive, royalty-free license to store,
copy, verify, analyze, publish and distribute it as needed to operate, secure,
audit and explain the service". The terms grant no license to anyone else, so
the library holds none of the files and records the term `reserved`. Each file
is identified below by its URL and the SHA-256 of the bytes that were
replayed, so a reader can fetch it and confirm it is the same file.
