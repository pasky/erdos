# problems/set_systems/E1022/claims

[[problems/set_systems/E1022/_index|..]]

[[problems/set_systems/E1022/claims/2013_10_10_wood|2013_10_10_wood]]: Wood's theorem gives, for every $t$, a triangle-free $2$-degenerate
$t$-uniform hypergraph with chromatic number 3 that has fewer than $2|X|$
edges inside every nonempty vertex set $X$, so no valid constant reaches 2.
erdosproblems.com credits it as the counterexample, and it is not refereed.

[[problems/set_systems/E1022/claims/2025_12_04_koishichan|2025_12_04_koishichan]]: For every $t$ there is a $(t+1)$-uniform hypergraph without property B with at
most $2|X|$ edges inside every vertex set $X$, so no valid constant exceeds 2
and $c_t$ cannot tend to infinity. erdosproblems.com accepts the claim, which
has a third-party Lean formalization.
