# problems/diophantine_problems/E0978/claims

[[problems/diophantine_problems/E0978/_index|..]]

[[problems/diophantine_problems/E0978/claims/1967_06_01_hooley|1967_06_01_hooley]]: Hooley (Mathematika 14, 1967) proved that if $f\in\mathbb{Z}[x]$ is
irreducible of degree $k\ge3$, then the number of $n\le x$ with $f(n)$
$(k-1)$-power-free is $c\,x+o(x)$, where $c$ is the Euler product of the local
factors.

[[problems/diophantine_problems/E0978/claims/2006_01_01_heath_brown|2006_01_01_heath_brown]]: Theorem 16 of Heath-Brown's 2006 lecture notes proves the Euler-product
asymptotic for the $r$-free values of an irreducible integer polynomial of
degree $d$ whenever $r\ge(3d+2)/4$. This range reaches $r=d-2$ for $d\ge10$.

[[problems/diophantine_problems/E0978/claims/2011_02_19_browning|2011_02_19_browning]]: In a refereed paper (Arch. Math. 96, 2011), Browning proves the Euler-product
asymptotic for the $r$-free values of an irreducible integer polynomial of
degree $d$ whenever $r\ge(3d+1)/4$. This range reaches $r=d-2$ for $d\ge9$.

[[problems/diophantine_problems/E0978/claims/2023_10_25_carella|2023_10_25_carella]]: Carella's 2023 preprint, unrefereed and unreviewed, claims asymptotic counts
of the squarefree values of $n^4+1$, $n^4+2$ and $n^4-2n^2+2$. This would
answer the question about $n^4+2$.

[[problems/diophantine_problems/E0978/claims/2026_03_31_deepmind|2026_03_31_deepmind]]: Answers a variant (the second question without the local condition at
exponent $k-2$), not the Statement (which imposes it), so it does not count
toward the problem's standing. Google DeepMind's prover agent, in a Lean proof
posted by Moritz Firsching, claims an irreducible sextic none of whose values
is $4$-power-free.

[[problems/diophantine_problems/E0978/claims/2026_08_11_zapata_ceballos_jalalvand|2026_08_11_zapata_ceballos_jalalvand]]: Zapata Ceballos and Jalalvand's unreviewed 2026 preprint claims a positive
density of squarefree values for monic irreducible polynomials of degree $2q$
whose field has a Galois subfield of degree $q$. This class includes $n^4+2$.

[[problems/diophantine_problems/E0978/claims/2026_09_24_openai|2026_09_24_openai]]: OpenAI's release proves that an irreducible integer polynomial of degree
$k\geq4$ with no fixed prime $(k-2)$-th power divisor takes $(k-2)$-power-free
values on a set of positive density. So $n^4+2$ is squarefree infinitely
often.
