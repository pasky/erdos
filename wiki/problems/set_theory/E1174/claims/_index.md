# problems/set_theory/E1174/claims

[[problems/set_theory/E1174/_index|..]]

[[problems/set_theory/E1174/claims/1989_01_01_shelah|1989_01_01_shelah]]: Shelah (Lecture Notes in Math. 1401, 1989) proved by forcing, from a
measurable cardinal or a weaker hypothesis, that there can consistently be a
$K_4$-free graph with a monochromatic triangle in every edge coloring with
countably many colors.

[[problems/set_theory/E1174/claims/1993_03_01_komjath_shelah|1993_03_01_komjath_shelah]]: Komjáth and Shelah (Acta Math. Hungar., 1993) proved, from a class of
measurable cardinals, that it is consistent that for every graph $Y$ and
cardinal $\mu$ some graph $X$ has $X\to(Y)^2_\mu$ and omits every complete
graph that $Y$ omits.
