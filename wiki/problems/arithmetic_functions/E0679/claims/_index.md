# problems/arithmetic_functions/E0679/claims

[[problems/arithmetic_functions/E0679/_index|..]]

[[problems/arithmetic_functions/E0679/claims/2026_01_11_dottedcalculator|2026_01_11_dottedcalculator]]: For every constant $C$, every large $n$ has some $k<n$ with
$\omega(n-k)\ge\log k/\log\log k+C$, so the version with an $O(1)$ error term
is false. The argument is a thread post by DottedCalculator, credited in the
erdosproblems.com remarks, and it comes with a Lean proof.

[[problems/arithmetic_functions/E0679/claims/2026_04_16_lau|2026_04_16_lau]]: Under a conjecture on short intervals containing integers with many prime
factors, Lau shows that every large $n$ has some large $k<n$ with
$\omega(n-k)>(1+\delta)\log k/\log\log k$. So the first question would have
the answer no.
