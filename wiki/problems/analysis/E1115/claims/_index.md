# problems/analysis/E1115/claims

[[problems/analysis/E1115/_index|..]]

[[problems/analysis/E1115/claims/1960_12_01_hayman|1960_12_01_hayman]]: Hayman's 1960 theorem shows that an entire function with
$\log M(r,f)=O((\log r)^2)$ tends to infinity along almost every ray, so a ray
gives a path with $\ell(r)=r$. This answers Problem 1115 yes for that growth
class.

[[problems/analysis/E1115/claims/1979_01_01_goldberg_eremenko|1979_01_01_goldberg_eremenko]]: Gol'dberg and Eremenko's 1979 Theorems 1 and 2 give entire functions with no
path on which $f\to\infty$ has length $O(r)$ inside the disc of radius $r$.
Such functions exist of order zero, growing barely above Hayman's threshold,
and of every finite order.

[[problems/analysis/E1115/claims/1980_02_01_toppila|1980_02_01_toppila]]: Toppila's 1980 note constructs, for every increasing $\varphi\to\infty$, an
entire function $f$ with $\log M(r,f)=O(\varphi(r)(\log r)^2)$ such that every
path on which $f\to\infty$ has $\limsup\ell(r)/r=\infty$. This is an
independent disproof.
