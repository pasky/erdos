# problems/integer_sequences/E0793/claims

[[problems/integer_sequences/E0793/_index|..]]

[[problems/integer_sequences/E0793/claims/2026_07_13_chojecki|2026_07_13_chojecki]]: Chojecki's manuscript of 13 July 2026 proves that the largest subset of
$\{1,\ldots,n\}$ with no member dividing the product of two others has size
$\pi(n)+(\frac{27}{2}+o(1))n^{2/3}/(\log n)^2$. The erdosproblems.com curator
has accepted it.

[[problems/integer_sequences/E0793/claims/2026_08_05_van_doorn|2026_08_05_van_doorn]]: A proof claim by van Doorn, made with GPT-5.5 Pro and Aristotle, is a Lean
file proving $F_k(n)=\pi(n)+(\Lambda_{k+1}+o(1))n^{2/(k+1)}/(\log n)^2$ for
every $k\ge2$, so the constant of Problem 793 exists. The file has not been
built here.
