# Covering Systems

[[problems/_index|..]]

[[problems/covering_systems/E0002/_index|E0002/]]: Asks whether a finite
covering system with distinct moduli can have arbitrarily large minimum modulus.
Hough proved an absolute bound, so the answer is no.

[[problems/covering_systems/E0007/_index|E0007/]]: Asks whether there is a
covering system of congruences whose moduli are distinct and all odd; open.

[[problems/covering_systems/E0008/_index|E0008/]]: Asks whether every finite
coloring of the integers admits a covering system whose moduli all receive the
same color. The answer is no.

[[problems/covering_systems/E0027/_index|E0027/]]: Asks whether there is a
constant $C>1$ such that for every $\epsilon>0$ and $N\ge1$ some
$\epsilon$-almost covering system has distinct moduli all in $[N,CN]$. The
answer is no.

[[problems/covering_systems/E0202/_index|E0202/]]: Asks how many congruence
classes with distinct moduli at most $N$ can be chosen so that no integer lies
in two of them; solved at the sharp logarithmic scale.

[[problems/covering_systems/E0203/_index|E0203/]]: Asks whether some integer
$m\ge1$ coprime to $6$ makes $2^k3^\ell m+1$ composite for all $k,\ell\ge0$;
open.

[[problems/covering_systems/E0204/_index|E0204/]]: Asks whether some $n$ has a
covering system whose moduli are the divisors of $n$ above $1$, with two classes
meeting only when their moduli are coprime. The answer is no.

[[problems/covering_systems/E0273/_index|E0273/]]: Asks whether there is a
covering system of congruences whose moduli are all of the form $p-1$ for primes
$p\ge5$; open.

[[problems/covering_systems/E0274/_index|E0274/]]: Asks whether a group can be
covered by more than one coset, the cosets having different sizes, so that each
element lies in exactly one of them; open.

[[problems/covering_systems/E0275/_index|E0275/]]: Asks whether a system of $r$
congruences that covers $2^r$ consecutive integers must cover every integer. The
answer is yes.

[[problems/covering_systems/E0276/_index|E0276/]]: Asks whether some
Fibonacci-type sequence has all terms composite while no integer shares a factor
with every term; open.

[[problems/covering_systems/E0277/_index|E0277/]]: Asks whether for every $c$
some $n$ with $\sigma(n)>cn$ admits no covering system whose moduli are distinct
divisors of $n$ above $1$. The answer is yes.

[[problems/covering_systems/E0278/_index|E0278/]]: Asks for the maximum density
of integers covered by choosing one congruence class for each modulus in a
finite set, and whether equal classes minimize the density. The second question
is settled, and a claimed answer to the first is pending.

[[problems/covering_systems/E0279/_index|E0279/]]: Asks whether for every
$k\ge3$ one can choose a class $a_p\pmod{p}$ for each prime $p$ so that every
large integer is $a_p+tp$ for some prime $p$ and integer $t\ge k$. A yes answer
is claimed and pending.

[[problems/covering_systems/E0280/_index|E0280/]]: Asks whether, for moduli
$n_1<n_2<\cdots$ with $n_k>(1+\epsilon)k\log k$ for some $\epsilon>0$ and all
$k$, the number of $m<n_k$ missed by the first $k$ congruences $a_i\pmod{n_i}$
is not $o(k)$. The answer is no.

[[problems/covering_systems/E0281/_index|E0281/]]: Asks whether moduli
$n_1<n_2<\cdots$ whose congruences always leave an uncovered set of density $0$
must have, for each $\epsilon>0$, an initial segment that always leaves density
below $\epsilon$. The answer is yes.

[[problems/covering_systems/E0586/_index|E0586/]]: Asks whether there is a
system of congruences covering all integers in which no modulus divides another.
The answer is no.

[[problems/covering_systems/E0947/_index|E0947/]]: Asks whether an exact
covering system exists, that is, finitely many congruence classes with distinct
moduli such that every integer satisfies exactly one of them. The answer is no.

[[problems/covering_systems/E1113/_index|E1113/]]: Asks whether some Sierpinski
number, an odd $m$ with $2^km+1$ never prime, has no finite set of primes
containing a divisor of every $2^km+1$; open.

[[problems/covering_systems/E1188/_index|E1188/]]: Asks for an estimate of the
number $F(x)$ of minimal covering systems with distinct moduli in $[1,x]$, where
minimal means no proper subsystem still covers every integer. A full answer is
claimed and pending.

[[problems/covering_systems/E1189/_index|E1189/]]: Asks about sets of distinct
moduli that cover the integers for some choice of residues while no proper
subset can, including how many have size $k$, the extreme values of their
largest modulus, and their largest reciprocal sum. Full answers are claimed and
pending.

[[problems/covering_systems/E1190/_index|E1190/]]: Asks for an estimate of
$\epsilon_m$, the supremum of $\sum 1/n_i$ over finite families of pairwise
disjoint congruence classes with distinct moduli $n_i>m$. It is solved at the
sharp logarithmic scale.
