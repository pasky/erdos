# Discrepancy

[[problems/_index|..]]

[[problems/discrepancy/E0067/_index|E0067/]]: Asks whether every
$f:\mathbb{N}\to\{-1,+1\}$ has unbounded discrepancy, that is, whether for every
$C>0$ some $d,m\geq 1$ give $\lvert\sum_{1\leq k\leq m}f(kd)\rvert>C$.

[[problems/discrepancy/E0161/_index|E0161/]]: Asks whether the least $m$ such
that some 2-coloring of the complete $t$-uniform hypergraph on $n$ vertices
gives every set of $m$ or more vertices at least an $\alpha$ fraction of edges
in each color varies continuously as $\alpha$ goes from 0 to 1/2, or jumps.

[[problems/discrepancy/E0162/_index|E0162/]]: Asks whether the size threshold
beyond which some 2-coloring of $K_n$ balances every large induced subgraph
grows like $c_\alpha\log n$. With the threshold corrected to the smallest such
size, this is the question of Problem 563, which is open.

[[problems/discrepancy/E0176/_index|E0176/]]: Asks for good upper bounds on
$N(k,\ell)$, the least $N$ such that every $f:\{1,\ldots,N\}\to\{-1,1\}$ has a
$k$-term arithmetic progression $P$ with $\lvert\sum_{n\in
P}f(n)\rvert\geq\ell$, in particular whether every $c>0$ has some $C>1$ with
$N(k,ck)\leq C^k$.

[[problems/discrepancy/E0177/_index|E0177/]]: Asks for the smallest $h(d)$ such
that one function $f:\mathbb{N}\to\{-1,1\}$ has $\lvert\sum_{n\in
P}f(n)\rvert\le h(d)$ for every $d\ge1$ and every finite arithmetic progression
$P$ with common difference $d$.

[[problems/discrepancy/E0178/_index|E0178/]]: Asks whether one function
$f:\mathbb{N}\to\{-1,1\}$ can keep the initial partial sums along each of
infinitely many prescribed integer sequences bounded.

[[problems/discrepancy/E0255/_index|E0255/]]: Asks whether every infinite
sequence in $[0,1]$ has a subinterval $I$ whose discrepancy $D_N(I)$ is
unbounded as $N\to\infty$.

[[problems/discrepancy/E0987/_index|E0987/]]: For a sequence $x_j\in(0,1)$, asks
whether $A_k=\limsup_n\lvert\sum_{j\le n}e(kx_j)\rvert$ must be unbounded in
$k$, and whether $A_k=o(k)$ is possible.

[[problems/discrepancy/E0988/_index|E0988/]]: Asks whether the least spherical
cap discrepancy of an $n$-point set on the unit sphere $S^2$ tends to infinity
with $n$.

[[problems/discrepancy/E0989/_index|E0989/]]: Asks whether the discrepancy
$f(r)$ of an infinite plane sequence, measured against circles of radius $r$ and
their area, is always unbounded, and how fast it grows.

[[problems/discrepancy/E0991/_index|E0991/]]: Asks whether the $n$-point sets on
the unit sphere that maximize the product of all pairwise distances have
spherical cap discrepancy $o(n)$.

[[problems/discrepancy/E0992/_index|E0992/]]: Asks whether, for every increasing
integer sequence $x_n$ and almost every $\alpha$, the discrepancy of $\{\alpha
x_n\}$ satisfies $D(N)\ll N^{1/2}(\log N)^{o(1)}$.

[[problems/discrepancy/E0994/_index|E0994/]]: Asks whether, for almost every
$\alpha$, the fractional parts $\{k\alpha\}$ visit every measurable set
$E\subseteq(0,1)$ with frequency $\lambda(E)$.

[[problems/discrepancy/E0995/_index|E0995/]]: Asks for the growth, for almost
every $\alpha$, of $\sum_{k\le N}f(\{\alpha n_k\})$, where $f\in L^2([0,1])$ and
$n_k$ is a lacunary integer sequence.

[[problems/discrepancy/E0997/_index|E0997/]]: Asks whether, for every $\alpha$,
the sequence $\{\alpha p_n\}$ over the primes $p_n$ fails to be well
distributed.

[[problems/discrepancy/E1028/_index|E1028/]]: Asks for an estimate of $H(n)$,
the least possible maximum over $X\subseteq\{1,\ldots,n\}$ of $\lvert\sum_{x\neq
y\in X}f(x,y)\rvert$ for a function $f$ with values $\pm1$.
