# problems/integer_sequences/E0879/claims

[[problems/integer_sequences/E0879/_index|..]]

[[problems/integer_sequences/E0879/claims/1984_01_01_erdos_van_lint|1984_01_01_erdos_van_lint]]: Erdős states in 1984, without proof, that for large $n$ an optimal admissible
set must contain an element that is not a prime power, which is the second
question at $k=2$. erdosproblems.com credits the result to Erdős and van Lint.

[[problems/integer_sequences/E0879/claims/2026_09_06_kitamura|2026_09_06_kitamura]]: Kitamura's 2026 Lean development, made with OpenAI Codex and ChatGPT Astra,
proves that for large $n$ every element of every optimal admissible set has at
most two distinct prime factors. So the second question fails at $k=3$.
