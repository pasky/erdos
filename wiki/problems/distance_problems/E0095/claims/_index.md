# problems/distance_problems/E0095/claims

[[problems/distance_problems/E0095/_index|..]]

[[problems/distance_problems/E0095/claims/2010_11_17_guth_katz|2010_11_17_guth_katz]]: Guth and Katz bound the number of ordered quadruples of $n$ plane points with
$|p_1-p_2|=|p_3-p_4|>0$ by $O(n^3\log n)$. That count is four times the sum of
the squared distance multiplicities, so this sum is $O(n^{3+\epsilon})$.
