# problems/discrepancy/E0255/claims

[[problems/discrepancy/E0255/_index|..]]

[[problems/discrepancy/E0255/claims/1968_01_01_schmidt|1968_01_01_schmidt]]: Schmidt's 1968 theorem says that for every sequence in the unit interval some
interval has unbounded counting discrepancy, which answers the question yes.
It is refereed, in the Quarterly Journal of Mathematics.

[[problems/discrepancy/E0255/claims/1972_01_01_schmidt|1972_01_01_schmidt]]: Schmidt's refereed 1972 theorem says that for every sequence in the unit
interval, the anchors $x$ at which $D_N([0,x))$ stays bounded are at most
countable. So all but countably many anchored intervals answer the question
yes.

[[problems/discrepancy/E0255/claims/1980_12_01_tijdeman_wagner|1980_12_01_tijdeman_wagner]]: Tijdeman and Wagner's refereed 1980 theorem says that every sequence in
$[0,1)$ has $\limsup_N\lvert D_N([0,x))\rvert/\log N\ge1/400$ for almost all
$x$. So almost every anchored interval answers the question yes.
