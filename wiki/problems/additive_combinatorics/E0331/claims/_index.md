# problems/additive_combinatorics/E0331/claims

[[problems/additive_combinatorics/E0331/_index|..]]

[[problems/additive_combinatorics/E0331/claims/1984_02_01_erdos_freud|1984_02_01_erdos_freud]]: Erdős and Freud (J. Number Theory 1984) answer the question in the negative
with the integers that use only even powers of two and those that use only odd
powers of two, for which $\liminf\min\{A(x),B(x)\}/\sqrt x=1/\sqrt2$. The
paper is refereed.

[[problems/additive_combinatorics/E0331/claims/2024_06_19_ruzsa|2024_06_19_ruzsa]]: Ruzsa takes the numbers with binary digits only in even places and the numbers
with binary digits only in odd places. Each set grows like $\sqrt N$, yet
every $n$ has at most one representation $a+b$, so the two sets have no
nonzero difference in common.
