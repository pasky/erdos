# problems/additive_bases/E0158/claims

[[problems/additive_bases/E0158/_index|..]]

[[problems/additive_bases/E0158/claims/1955_01_01_erdos|1955_01_01_erdos]]: Erdős proved that every infinite Sidon set $A$ satisfies
$\liminf_{N\to\infty}\lvert A\cap\{1,\ldots,N\}\rvert/N^{1/2}=0$. This answers
Problem 158 yes for the sets in which each integer has at most one
representation.
