# problems/arithmetic_functions/E1122/claims

[[problems/arithmetic_functions/E1122/_index|..]]

[[problems/arithmetic_functions/E1122/claims/1946_01_01_erdos|1946_01_01_erdos]]: Erdős proves, in a refereed paper, that an additive function $f$ with
$f(n+1)\ge f(n)$ for every $n$, or with $f(n+1)-f(n)\to0$, is a constant
multiple of $\log n$. The monotone case is the case of an empty set of
decreases.

[[problems/arithmetic_functions/E1122/claims/2021_08_27_mangerel|2021_08_27_mangerel]]: Mangerel proves that a completely additive function with no outsized prime
values is a constant multiple of $\log n$ when the number of its decreases up
to $X$ is $\ll X/(\log X)^{2+\delta}$ for some $\delta>0$. The paper is
refereed.

[[problems/arithmetic_functions/E1122/claims/2026_09_08_gu|2026_09_08_gu]]: A 2026 Zenodo manuscript credited to GPT-6 Astra and claimed by Qiyuan Gu
asserts that an additive function $f$ with $f(n+1)<f(n)$ only for a
density-zero set of $n$ is a nonnegative multiple of $\log n$. It is a full
claim, pending review.
