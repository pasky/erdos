# Running least common multiples: distinct values and multiplicities

[[irrationality/_index|..]]

***

Cook, Will, *Running least common multiples: distinct values and multiplicities*, July 2026, revised 5 October 2026, 73-page author-hosted edition.

The opening distinguishes the reciprocal sum over distinct running LCMs from the sum retaining every smooth-number multiplicity. It reports irrationality for the distinct-value sum at {2,3,5}, and a two-prime Hecke–Mahler reduction credited to prior work. Its residue criterion for the repeated three-prime sum leaves the required arithmetic condition open. These assertions are source-reported, with no verification tier assigned here.
