# problems/analysis/E0517/claims

[[problems/analysis/E0517/_index|..]]

[[problems/analysis/E0517/claims/1927_01_01_biernacki|1927_01_01_biernacki]]: Biernacki proves that an entire gap series whose exponents satisfy
$\sum_k1/n_k<\infty$ takes every value infinitely often, which covers a
subclass of Problem 517 with functions of any order. The venue's refereeing is
not shown.

[[problems/analysis/E0517/claims/1929_12_01_polya|1929_12_01_polya]]: Pólya proves that an entire function of finite order whose exponent gaps are
unbounded takes every value infinitely often. This settles the finite-order
case of Problem 517, and the paper is refereed in Math. Z.

[[problems/analysis/E0517/claims/1983_01_01_murai|1983_01_01_murai]]: Murai proves that an entire function whose exponents satisfy
$\sum_k1/n_k<\infty$ has no finite deficient value, so it takes every value
infinitely often. The paper is refereed in Ann. Inst. Fourier.
