# problems/distance_problems/E1083/claims

[[problems/distance_problems/E1083/_index|..]]

[[problems/distance_problems/E1083/claims/2026_08_14_tidor_yu_zakharov|2026_08_14_tidor_yu_zakharov]]: An arXiv preprint by Tidor, Yu and Zakharov claims that $N$ points in
three-dimensional space determine at least $N^{2/3-o(1)}$ distinct distances.
With Erdős's grid bound this gives $f_3(n)=n^{2/3-o(1)}$ and answers the
particular question for $d=3$.

[[problems/distance_problems/E1083/claims/2026_09_23_openai|2026_09_23_openai]]: An OpenAI release preprint, with no Lean formalization, claims that for every
$d\ge3$ each set of $n$ points in $\mathbb{R}^d$ determines at least
$c_d\,n^{2/d}$ distinct distances, so that $f_d(n)$ has order $n^{2/d}$.
