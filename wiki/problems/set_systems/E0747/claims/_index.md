# problems/set_systems/E0747/claims

[[problems/set_systems/E0747/_index|..]]

[[problems/set_systems/E0747/claims/2008_03_24_johansson_kahn_vu|2008_03_24_johansson_kahn_vu]]: Johansson, Kahn and Vu prove that the threshold for a perfect matching in a
random $3$-uniform hypergraph on $3n$ vertices is of order $n\log n$, settling
Shamir's problem up to the constant. The result was refereed in 2008 and is
credited.

[[problems/set_systems/E0747/claims/2019_09_15_kahn|2019_09_15_kahn]]: Kahn proves, in a paper refereed in 2023, that a random $r$-uniform hypergraph
on $N$ vertices with more than $(1+\varepsilon)(N/r)\log N$ edges almost
surely has a perfect matching. So the threshold for the problem is asymptotic
to $n\log n$.
