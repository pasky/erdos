# problems/extremal_graph_theory/E0745/claims

[[problems/extremal_graph_theory/E0745/_index|..]]

[[problems/extremal_graph_theory/E0745/claims/1980_01_01_komlos_sulyok_szemeredi|1980_01_01_komlos_sulyok_szemeredi]]: Komlós, Sulyok and Szemerédi bound the second largest component by $O(\log n)$
at edge probability $\lambda/n$ with $\lambda>1$, the supercritical case the
site's label credits. The result is correct, but the Statement has edge
probability $1/n$, so it does not count toward the problem's standing.

[[problems/extremal_graph_theory/E0745/claims/1997_04_01_aldous|1997_04_01_aldous]]: In a refereed paper in Ann. Probab. 25 (1997), Aldous proves that the ordered
component sizes of $G(n,1/n+tn^{-4/3})$, scaled by $n^{-2/3}$, converge to
Brownian excursion lengths. At $t=0$ the second largest component has order
$n^{2/3}$.

[[problems/extremal_graph_theory/E0745/claims/2026_08_25_alexeev|2026_08_25_alexeev]]: Boris Alexeev's Lean development states that the second largest component of
$G(n,\lambda/n)$ has order $n^{2/3}$ at $\lambda=1$, the problem's parameter,
and logarithmic order with an explicit coefficient for every fixed
$\lambda\ne1$. This corpus has not built it.

[[problems/extremal_graph_theory/E0745/claims/2026_10_04_ding|2026_10_04_ding]]: Jingxuan Ding's Lean development describes the second largest component of the
uniform random graph $G(n,M)$ in five sparse regimes, with order $n^{2/3}$ in
the critical window and logarithmic order away from it. This corpus has not
built it.
