# problems/additive_bases/E1194/claims

[[problems/additive_bases/E1194/_index|..]]

[[problems/additive_bases/E1194/claims/2004_11_03_lev|2004_11_03_lev]]: Lev's greedy construction gives a perfect difference set whose elements added
at step $n$ are $O(n^3)$. This set therefore has $a_n\ll n^3$, so $a_n/n$ need
not grow faster than $n^2$.

[[problems/additive_bases/E1194/claims/2026_04_23_price|2026_04_23_price]]: An Overleaf note posted by Liam Price and written by GPT-5.4 Pro claims that
$a_n\gg n^{3/2}$ for infinitely many $n$. It is unrefereed and unreviewed.

[[problems/additive_bases/E1194/claims/2026_05_02_mazur|2026_05_02_mazur]]: Lech Mazur, with GPT-5.5 Pro, Codex and a verification harness, claims that
$a_n>n^2/(2\log2\,(\log n-\log\log n+B))$ for infinitely many $n$, for every
$B$ above an explicit constant. A Lean proof comes with it but was not built
here, and the claim is unrefereed.
