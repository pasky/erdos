# problems/set_systems/E0835/claims

[[problems/set_systems/E0835/_index|..]]

[[problems/set_systems/E0835/claims/2025_12_31_ma_tang|2025_12_31_ma_tang]]: Ma and Tang's note claims that the Johnson graph $J(2k,k)$ has chromatic
number greater than $k+1$ whenever $k>2$ and $k+1$ is not prime, so that no
coloring of the kind asked for exists for those $k$. This is a partial answer
of no.

[[problems/set_systems/E0835/claims/2026_01_23_deepmind|2026_01_23_deepmind]]: AlphaProof found a Lean proof that the Johnson graph $J(18,9)$ does not have
chromatic number $10$, so the case $k=9$ of the question has answer no. The
proof was posted in a formal-conjectures pull request and removed before the
merge.
