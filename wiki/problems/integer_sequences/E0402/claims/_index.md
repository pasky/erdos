# problems/integer_sequences/E0402/claims

[[problems/integer_sequences/E0402/_index|..]]

[[problems/integer_sequences/E0402/claims/1986_03_01_szegedy|1986_03_01_szegedy]]: Szegedy proves that for $n$ at least an effectively computable $n_0$, every
set of $n$ distinct positive integers has a pair with $a/\gcd(a,b)\ge n$.
Equality holds only for the multiples $\{k,2k,\ldots,nk\}$ and their
reciprocal set $\{k/1,\ldots,k/n\}$.

[[problems/integer_sequences/E0402/claims/1987_09_01_zaharescu|1987_09_01_zaharescu]]: In a refereed paper in J. Number Theory 27 (1987), Zaharescu proves Graham's
conjecture for every chain of $n$ positive integers with $n$ sufficiently
large. The proof uses the distance from $2n$ to the largest prime below it and
Huxley's prime-gap bound.

[[problems/integer_sequences/E0402/claims/1996_01_01_balasubramanian_soundararajan|1996_01_01_balasubramanian_soundararajan]]: Balasubramanian and Soundararajan prove Graham's conjecture for every set of
$N$ integers, so every finite set $A$ has two members $a,b$ with
$\gcd(a,b)\le a/|A|$. The refereed paper appeared in Acta Arithmetica 75
(1996), and erdosproblems.com credits it.
