# problems/integer_sequences/E0332/claims

[[problems/integer_sequences/E0332/_index|..]]

[[problems/integer_sequences/E0332/claims/1979_10_01_stewart_tijdeman|1979_10_01_stewart_tijdeman]]: Stewart and Tijdeman's refereed 1979 Theorem 2 shows that for a set of
positive upper density, finitely many translates of its set of differences
occurring infinitely often cover the non-negative integers. Hence that set of
differences has bounded gaps.

[[problems/integer_sequences/E0332/claims/2026_05_04_aditya|2026_05_04_aditya]]: A note linked from the Problem 332 thread on 4 May 2026 claims a proof that
the differences occurring infinitely often have bounded gaps for every set of
positive upper Banach density. It was posted as an observation by GPT 5.5 pro.
