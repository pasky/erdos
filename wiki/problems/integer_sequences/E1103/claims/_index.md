# problems/integer_sequences/E1103/claims

[[problems/integer_sequences/E1103/_index|..]]

[[problems/integer_sequences/E1103/claims/2004_06_30_konyagin|2004_06_30_konyagin]]: Konyagin's refereed 2004 bound on the largest subset of $[1,N]$ with
squarefree sums, $N^{11/15}$ times a subexponential factor, gives
$a_j\gg j^{15/11-o(1)}$ for every infinite set with squarefree sums.

[[problems/integer_sequences/E1103/claims/2025_11_30_van_doorn_tao|2025_11_30_van_doorn_tao]]: Van Doorn and Tao's first arXiv version (2025) proves that every infinite set
with squarefree sums has $a_j\gg j^{4/3}$, and that some such set of
squarefree numbers has $a_j\le\exp(Cj/\log j)$. The true growth rate is not
settled.

[[problems/integer_sequences/E1103/claims/2026_07_23_hu|2026_07_23_hu]]: Xiyu Hu's July 2026 note constructs an infinite set with squarefree pairwise
sums, doubles included, whose counting function is $\gg(\log x)^2$, so
$a_j\le\exp(C\sqrt j)$. The note comes with a partial Lean 4 development.
