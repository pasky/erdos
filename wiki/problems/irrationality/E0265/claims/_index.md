# problems/irrationality/E0265/claims

[[problems/irrationality/E0265/_index|..]]

[[problems/irrationality/E0265/claims/2024_11_27_kovac_tao|2024_11_27_kovac_tao]]: Kovač and Tao construct a strictly increasing integer sequence with both
reciprocal sums rational and $a_n^{1/\beta^n}\to\infty$, for any base
$\beta<\sqrt{6/5}$. The exact exponent is not determined.

[[problems/irrationality/E0265/claims/2026_08_28_cam|2026_08_28_cam]]: Cam's 2026 write-up, posted to the problem's proof-claims thread, asserts that
for every $\beta<(\sqrt{13}-1)/2$ there is an increasing integer sequence with
both reciprocal sums rational and $a_n^{1/\beta^n}$ unbounded.

[[problems/irrationality/E0265/claims/2026_09_07_kitamura|2026_09_07_kitamura]]: Kenta Kitamura's Lean 4 development, made with ChatGPT and OpenAI Codex using
GPT-6 (Astra), claims that no increasing sequence with both reciprocal sums
rational has $\limsup a_n^{1/2^n}>1$. The exact exponent is open.
