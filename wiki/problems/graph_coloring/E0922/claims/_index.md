# problems/graph_coloring/E0922/claims

[[problems/graph_coloring/E0922/_index|..]]

[[problems/graph_coloring/E0922/claims/1970_01_01_folkman|1970_01_01_folkman]]: Folkman (1970) proves that if every $n$-vertex subgraph of a graph has an
independent set of size at least $(n-k)/2$, then the graph has chromatic
number at most $k+2$. This answers the question of Erdős and Hajnal for every
$k$.
