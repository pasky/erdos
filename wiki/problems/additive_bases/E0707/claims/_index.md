# problems/additive_bases/E0707/claims

[[problems/additive_bases/E0707/_index|..]]

[[problems/additive_bases/E0707/claims/1947_12_01_hall|1947_12_01_hall]]: Hall's 1947 remark shows that the Sidon set $\{-8,-6,0,1,4\}$, equivalently
$\{1,3,9,10,13\}$, lies in no perfect difference set modulo any $v$, refuting
the conjecture for every modulus. It was recognized as the first disproof
in 2025.

[[problems/additive_bases/E0707/claims/2025_10_22_alexeev_mixon|2025_10_22_alexeev_mixon]]: Alexeev and Mixon show that the Sidon set $\{1,2,4,8\}$ extends to no perfect
difference set modulo $p^2+p+1$ with $p$ prime, and $\{1,2,4,8,13\}$ to none
modulo any $v$, disproving the prize conjecture. They verified both results in
Lean.
