# problems/ramsey_theory/E0615/claims

[[problems/ramsey_theory/E0615/_index|..]]

[[problems/ramsey_theory/E0615/claims/2012_08_16_fox_loh_zhao|2012_08_16_fox_loh_zhao]]: Theorem 1.10 of Fox, Loh and Zhao (Combinatorica 2015, refereed) gives
$\mathbf{RT}(n,K_4,m)\ge(1/8-o(1))n^2$ when $m=ne^{-f(n)}$ with
$f(n)=o((\log n/\log\log n)^{1/2})$. This range contains $n/\log n$, so the
answer to Problem 615 is no.
