# problems/irrationality/E0257/claims

[[problems/irrationality/E0257/_index|..]]

[[problems/irrationality/E0257/claims/1948_07_08_erdos|1948_07_08_erdos]]: Erdős's 1948 theorem says that $\sum_n1/(t^n-1)$ is irrational for every
integer $t$ with $|t|>1$. This settles the problem for the support $\mathbb N$
and, through the base $t=2^d$, for every set of multiples $d\mathbb N$.

[[problems/irrationality/E0257/claims/1965_12_13_erdos|1965_12_13_erdos]]: Erdős's 1968 paper in the Mathematics Student proves that
$\sum_{n\in A}1/(t^n-1)$ is irrational for every integer base $t\ge2$ when $A$
is a pairwise coprime set with convergent reciprocal sum. This covers one
class of supports.

[[problems/irrationality/E0257/claims/2019_08_14_duverney_tachiya|2019_08_14_duverney_tachiya]]: Duverney and Tachiya's 2019 paper proves that $\sum_{n\in A}1/(q^n-1)$ is
irrational when $A$ is the set of products of powers below $s$ of a pairwise
coprime, polynomially bounded sequence. These sets include the squarefree
integers.

[[problems/irrationality/E0257/claims/2025_12_01_tao_teravainen|2025_12_01_tao_teravainen]]: Tao and Teräväinen's theorem that $\sum_p1/(2^p-1)$ is irrational settles the
problem for the support consisting of the primes. This case is Problem 69.

[[problems/irrationality/E0257/claims/2026_09_11_cook|2026_09_11_cook]]: Cook's 2026 note, drafted with AI agents, claims that $\sum_{a\in A}1/(b^a-1)$
is irrational at every integer base $b\ge2$ for every infinite set $A$ with
convergent reciprocal sum.

[[problems/irrationality/E0257/claims/2026_09_25_cook|2026_09_25_cook]]: A registered partial claim gives irrationality under a finite-prime weighted summability condition and an all-base conclusion for every infinite subset of a qualifying host.
