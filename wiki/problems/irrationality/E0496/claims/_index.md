# problems/irrationality/E0496/claims

[[problems/irrationality/E0496/_index|..]]

[[problems/irrationality/E0496/claims/1989_01_01_margulis|1989_01_01_margulis]]: Margulis's theorem on indefinite irrational ternary forms gives, for every
irrational $\alpha>0$, positive integers $x,y,z$ with $|x^2+y^2-z^2\alpha|$
arbitrarily small. The erdosproblems.com curator records the problem as
proved.

[[problems/irrationality/E0496/claims/2026_08_21_alexeev|2026_08_21_alexeev]]: Answers the erdosproblems.com wording (every irrational $\alpha$), not the
modified Statement ($\alpha>0$), so it does not count toward the problem's
standing. A Lean theorem in Alexeev's repository, by Codex and GPT-5.6 Sol,
refutes that wording at $\alpha=-\sqrt2$ and $\epsilon=1$.
