# problems/set_systems/E0725/claims

[[problems/set_systems/E0725/_index|..]]

[[problems/set_systems/E0725/claims/1946_04_01_erdos_kaplansky|1946_04_01_erdos_kaplansky]]: Erdős and Kaplansky (1946) prove that the number of $k\times n$ Latin
rectangles is asymptotic to $e^{-k(k-1)/2}(n!)^k$ for
$k<(\log n)^{3/2-\epsilon}$. This is a partial answer to the problem's request
for an asymptotic formula.

[[problems/set_systems/E0725/claims/1951_01_01_yamamoto|1951_01_01_yamamoto]]: Yamamoto (1951) extends the Erdős–Kaplansky asymptotic for the number of
$k\times n$ Latin rectangles to every $k<n^{1/3-\delta}$, confirming their
conjecture. This is a partial answer to the problem's request for a formula.

[[problems/set_systems/E0725/claims/1984_01_01_godsil_mckay|1984_01_01_godsil_mckay]]: Godsil and McKay (announced 1984, published 1990) prove an asymptotic formula
for the number of $k\times n$ Latin rectangles for every $k=o(n^{6/7})$, a
partial answer to the problem. The same formula was later claimed for all
sublinear $k$.

[[problems/set_systems/E0725/claims/2026_08_03_li|2026_08_03_li]]: Li's 2026 manuscript states the Godsil–McKay formula for the number of
$k\times n$ Latin rectangles for every $k=o(n)$, with a Lean development the
author reports as complete. It is AI-assisted, unreviewed and not refereed.
