# problems/set_theory/E0601/claims

[[problems/set_theory/E0601/_index|..]]

[[problems/set_theory/E0601/claims/1970_01_01_erdos_hajnal_milner|1970_01_01_erdos_hajnal_milner]]: Erdős, Hajnal and Milner (Balatonfüred colloquium, 1970) prove, as Theorem 7,
that a graph with no infinite path on an ordered set of type
$\omega\theta<\omega_1^{\omega+2}$ has an independent set of the same type.

[[problems/set_theory/E0601/claims/1986_04_01_larson|1986_04_01_larson]]: Larson (J. London Math. Soc., 1986) proved that if there is no scale of order
type $\omega_1$ under eventual domination, then every graph on
$\omega_1^{\omega+2}$ has an infinite path or an independent set of that order
type. That ordinal is the first one not settled in ZFC.

[[problems/set_theory/E0601/claims/1987_09_01_larson|1987_09_01_larson]]: Larson (Trans. Amer. Math. Soc., 1987) proved under GCH that for each $n\ge2$,
cofinally many ordinals below $\omega_n$ carry a graph with no infinite path
and no independent set of their own order type.

[[problems/set_theory/E0601/claims/1990_04_01_baumgartner_larson|1990_04_01_baumgartner_larson]]: Baumgartner and Larson (Ann. Pure Appl. Logic, 1990) proved that Jensen's
$\diamondsuit$ gives, on every ordinal below $\omega_2$, a graph with no
infinite path and no independent set of type $\omega_1^{\omega+2}$. So every
limit $\alpha\in[\omega_1^{\omega+2},\omega_2)$ fails the property.

[[problems/set_theory/E0601/claims/1990_04_01_larson|1990_04_01_larson]]: Larson (Ann. Pure Appl. Logic, 1990) proved that under Martin's axiom every
limit ordinal below the continuum has the property: every graph on it has an
infinite path or an independent set of its order type.
