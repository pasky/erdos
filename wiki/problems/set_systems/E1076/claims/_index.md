# problems/set_systems/E1076/claims

[[problems/set_systems/E1076/_index|..]]

[[problems/set_systems/E1076/claims/2018_02_12_glock_kuhn_lo_osthus|2018_02_12_glock_kuhn_lo_osthus]]: For every fixed $k$, Glock, Kühn, Lo and Osthus build $n$-vertex partial
Steiner triple systems with $(1/6-o(1))n^2$ triples and no $j$ vertices
spanning $j-2$ triples for $4\le j\le k$. With linearity, this refereed
Combinatorica result, credited by the curator, settles the modified
Statement.

[[problems/set_systems/E1076/claims/2018_08_03_bohman_warnke|2018_08_03_bohman_warnke]]: For every fixed girth bound $\ell$ there are partial Steiner triple systems on
$n$ vertices with $(1-n^{-\beta})n^2/6$ triples and no $j$ vertices spanning
$j-2$ triples for $j\le\ell$. With linearity this settles the modified
Statement, and it is refereed and credited by the site's curator.

[[problems/set_systems/E1076/claims/2018_09_06_glock|2018_09_06_glock]]: Correct, but answers the site's wording (the single family $F_5$), not the
modified Statement (the cumulative family), so it does not count toward the
problem's standing. The most triples on $n$ points with no three spanning at
most five points is $(1+o(1))n^2/5$, refereed in Bull. Lond. Math. Soc.

[[problems/set_systems/E1076/claims/2022_09_28_glock_joos_kim_kuhn_lichev_pikhurko|2022_09_28_glock_joos_kim_kuhn_lichev_pikhurko]]: Correct, but answers the site's wording (the single family $F_6$), not the
modified Statement (the cumulative family), so it does not count toward the
problem's standing. The $(6,4)$ limit is $7/36$, not $1/6$, refereed in Proc.
Amer. Math. Soc. Ser. B.

[[problems/set_systems/E1076/claims/2024_03_07_glock_kim_lichev_pikhurko_sun|2024_03_07_glock_kim_lichev_pikhurko_sun]]: Correct, but answers the site's wording (the single families $F_7$, $F_8$ and

[[problems/set_systems/E1076/claims/2025_06_02_pikhurko_sun|2025_06_02_pikhurko_sun]]: Correct, but answers the site's wording (the single family $F_{10}$), not the

[[problems/set_systems/E1076/claims/2026_08_17_alexeev|2026_08_17_alexeev]]: Answers the site's wording (the single family $F_k$), not the modified

$92/529>1/6$. The file is not built here.

[[problems/set_systems/E1076/claims/2026_09_29_chao_huang_liu|2026_09_29_chao_huang_liu]]: Answers the site's wording (the single families $F_k$), not the modified

[[problems/set_systems/E1076/claims/2026_10_02_bodnar_pikhurko_sun_wang_zeng|2026_10_02_bodnar_pikhurko_sun_wang_zeng]]: Answers the site's wording (the single family $F_{11}$), not the modified
