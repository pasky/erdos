# problems/integer_sequences/E0535/claims

[[problems/integer_sequences/E0535/_index|..]]

[[problems/integer_sequences/E0535/claims/1964_03_20_erdos|1964_03_20_erdos]]: Erdős's refereed 1964 theorem (Mathematics of Computation) shows that for each
fixed $r$ the largest set of integers up to $N$ with no $r$ of equal pairwise
gcd has size between $N^{c_r/\log\log N}$ and $N^{3/4+\varepsilon}$.

[[problems/integer_sequences/E0535/claims/1970_11_01_abbott_hanson|1970_11_01_abbott_hanson]]: Abbott and Hanson (Bull. London Math. Soc. 1970) improve Erdős's upper bound
for the largest set of integers up to $N$ with no $r$ of equal pairwise gcd to
$N^{1/2+\varepsilon}$, as Erdős's 1973 survey reports it. The paper is
refereed.
