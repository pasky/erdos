# problems/divisors/E0056/claims

[[problems/divisors/E0056/_index|..]]

[[problems/divisors/E0056/claims/1994_01_01_ahlswede_khachatrian|1994_01_01_ahlswede_khachatrian]]: Ahlswede and Khachatrian show that for $k=212$ and $N$ in an explicit range,
some subset of $\{1,\ldots,N\}$ with no $213$ pairwise coprime elements is
larger than the set of multiples of the first $212$ primes. So the conjectured
extremal set fails.

[[problems/divisors/E0056/claims/1995_01_01_ahlswede_khachatrian|1995_01_01_ahlswede_khachatrian]]: Ahlswede and Khachatrian prove that for every $k$ there is $n(k)$ such that
for every $N>n(k)$ the multiples of the first $k$ primes form the unique
largest subset of $\{1,\ldots,N\}$ with no $k+1$ pairwise coprime elements.
