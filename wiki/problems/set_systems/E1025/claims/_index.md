# problems/set_systems/E1025/claims

[[problems/set_systems/E1025/_index|..]]

[[problems/set_systems/E1025/claims/1958_03_01_erdos_hajnal|1958_03_01_erdos_hajnal]]: Erdős and Hajnal (1958) prove that every map sending each pair of an $n$-set
to a point outside it has an independent set of order $n^{1/3}$, and that some
such map has none above order $\sqrt{n\log n}$. The paper is refereed, and
both bounds are superseded.

[[problems/set_systems/E1025/claims/1972_05_01_spencer|1972_05_01_spencer]]: Spencer's 1972 Turán theorem for $k$-graphs gives every pair mapping on an
$n$-set an independent set of order $\sqrt n$, the lower-bound half of the
problem. The curator credits the paper, which is refereed and appeared in
Discrete Mathematics.

[[problems/set_systems/E1025/claims/1991_05_01_furedi|1991_05_01_furedi]]: Füredi's 1991 paper in SIAM J. Discrete Math. proves
$\frac{2\sqrt3}{9}\sqrt n<g(n)<2\sqrt n$, with the lower bound from Spencer's
theorem and the upper bound from a block construction. This settled the order
of $g(n)$ before Conlon, Fox and Sudakov.

[[problems/set_systems/E1025/claims/2015_07_02_conlon_fox_sudakov|2015_07_02_conlon_fox_sudakov]]: Conlon, Fox and Sudakov, in a refereed paper in J. Combin. Theory Ser. B,
construct a pair mapping on a square-grid ground set with no independent set
larger than a constant times $\sqrt n$. With Spencer's lower bound, this shows
that $g(n)$ has order $\sqrt n$.
