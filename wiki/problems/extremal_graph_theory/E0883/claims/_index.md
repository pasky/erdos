# problems/extremal_graph_theory/E0883/claims

[[problems/extremal_graph_theory/E0883/_index|..]]

[[problems/extremal_graph_theory/E0883/claims/1996_12_02_erdos_sarkozy|1996_12_02_erdos_sarkozy]]: Erdős and Sárközy prove that for large $n$, the coprime graph of a set above
the triangle threshold contains every odd cycle of length up to $2cn+1$, for
some unspecified $c>0$. This is a weaker form of the first question.

[[problems/extremal_graph_theory/E0883/claims/1999_05_01_sarkozy|1999_05_01_sarkozy]]: Theorem 1 of Sárközy (Discrete Math. 1999) shows that for large $n$, the
coprime graph of any set above the triangle threshold contains a complete
$K(1,\ell,\ell)$ subgraph with $\ell$ of order $\log n/\log\log\log n$. This
answers the second question.

[[problems/extremal_graph_theory/E0883/claims/2026_07_27_della_pietra|2026_07_27_della_pietra]]: Della Pietra's manuscript and Lean development claim the first question of
Problem 883 for all sufficiently large $n$: a set above the triangle threshold
has every odd cycle of length at most $n/3+1$ in its coprime graph, and $1/6$
is sharp. The claim is unreviewed.

[[problems/extremal_graph_theory/E0883/claims/2026_10_05_pan|2026_10_05_pan]]: Pan's manuscript and Lean development claim the first question of Problem 883
for every $n$, using an analytic argument for $n\ge200000$ and finite
certificates below that. The claim does not address the second question and is
unreviewed.
