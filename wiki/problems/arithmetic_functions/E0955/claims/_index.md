# problems/arithmetic_functions/E0955/claims

[[problems/arithmetic_functions/E0955/_index|..]]

[[problems/arithmetic_functions/E0955/claims/2014_05_14_troupe|2014_05_14_troupe]]: Troupe proves that, for each $\epsilon>0$, $\omega(s(n))$ and $\Omega(s(n))$
are within $\epsilon\log\log s(n)$ of $\log\log s(n)$ for all but $o(x)$
integers $n\le x$. So the integers with abnormally many or few prime factors
have a density-zero preimage under $s$.

[[problems/arithmetic_functions/E0955/claims/2015_04_01_pollack|2015_04_01_pollack]]: Pollack proves that $s(n)$ is prime for only $O(x/\log x)$ integers $n\le x$,
so the preimage of the primes under $s$ has density zero.

[[problems/arithmetic_functions/E0955/claims/2015_06_15_pollack|2015_06_15_pollack]]: Pollack proves that, for each base $g\ge2$, $s(n)$ is a base-$g$ palindrome
only for a density-zero set of $n$. This is the conjecture in the case of the
palindromes.

[[problems/arithmetic_functions/E0955/claims/2017_06_09_pollack_pomerance_thompson|2017_06_09_pollack_pomerance_thompson]]: Pollack, Pomerance and Thompson prove that a set of at most $x^{1/2+o(1)}$
integers has $o(x)$ preimages $n\le x$ under $s$. This settles the conjecture
for every target set with counting function $y^{1/2+o(1)}$.

[[problems/arithmetic_functions/E0955/claims/2019_02_28_troupe|2019_02_28_troupe]]: Troupe proves that the number of $n\le x$ for which $s(n)$ is a sum of two
squares has order $x/\sqrt{\log x}$. So the sums of two squares have a
density-zero preimage under $s$.

[[problems/arithmetic_functions/E0955/claims/2021_06_20_pollack_troupe|2021_06_20_pollack_troupe]]: Pollack and Troupe prove that $\omega(s(n))$ satisfies the Erdős–Kac law. So
the integers $m$ whose number of prime factors is far from $\log\log m$ in
units of $\sqrt{\log\log m}$ have a density-zero preimage under $s$.

[[problems/arithmetic_functions/E0955/claims/2023_07_24_benli_cesana_dartyge_dombrowsky_thompson|2023_07_24_benli_cesana_dartyge_dombrowsky_thompson]]: Benli, Cesana, Dartyge, Dombrowsky and Thompson prove that, for each base
$g\ge3$, the number of $n\le x$ for which every base-$g$ digit of $s(n)$ lies
in a fixed proper digit set is $O(x\exp(-(\log\log x)^\gamma))$.

[[problems/arithmetic_functions/E0955/claims/2026_07_21_benli_dartyge_dombrowsky_pollack_thompson|2026_07_21_benli_dartyge_dombrowsky_pollack_thompson]]: Benli, Dartyge, Dombrowsky, Pollack and Thompson extend the missing-digit
preimage bound to every base $g\ge2$. They supply the binary case, $g=2$, in
an appendix.
