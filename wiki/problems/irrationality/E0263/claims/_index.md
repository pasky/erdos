# problems/irrationality/E0263/claims

[[problems/irrationality/E0263/_index|..]]

[[problems/irrationality/E0263/claims/2026_02_27_deepmind|2026_02_27_deepmind]]: Answers a variant (erdosproblems.com's earlier wording, without the hypothesis
that $a_n$ be increasing), not the Statement (increasing sequences), so it
does not count toward the problem's standing. A DeepMind prover agent found a
Lean proof that a sequence equal to $2^{3^n}$ except on a sparse set of
indices, where it is $2^n$, is an irrationality sequence with
$a_n^{1/n}\not\to\infty$.

[[problems/irrationality/E0263/claims/2026_05_09_price|2026_05_09_price]]: A claimed counterexample, found by GPT-5.5 Pro and posted by Price, is a
sequence asserted to be an increasing irrationality sequence of the problem's
kind with $a_n^{1/n}\not\to\infty$. The first question is open.

[[problems/irrationality/E0263/claims/2026_08_01_lystad|2026_08_01_lystad]]: Does not address the Statement (whether $a_n=2^{2^n}$ is an irrationality
sequence, and whether every such sequence has $a_n^{1/n}\to\infty$), so it
does not count toward the problem's standing. T. Alexander Lystad's Lean
development, generated with Kimi K3, proves the folklore criterion that
$c\,a_n^{2+\epsilon}\le a_{n+1}$ makes an irrationality sequence.

[[problems/irrationality/E0263/claims/2026_08_02_lystad_general|2026_08_02_lystad_general]]: Does not address the Statement (whether $a_n=2^{2^n}$ is an irrationality
sequence, and whether every such sequence has $a_n^{1/n}\to\infty$), so it
does not count toward the problem's standing. Tinius Alexander Lystad's Lean
development, generated with Kimi K3, proves that every sequence with
$a_n^{1/2^n}\to\infty$ has irrational reciprocal sum.

[[problems/irrationality/E0263/claims/2026_08_02_lystad_monotone|2026_08_02_lystad_monotone]]: Does not address the Statement (whether $a_n=2^{2^n}$ is an irrationality
sequence, and whether every such sequence has $a_n^{1/n}\to\infty$), so it
does not count toward the problem's standing. T. Alexander Lystad's Lean
development, generated with Kimi K3, proves that a monotone sequence with
$a_n^{1/2^n}\to\infty$ has irrational reciprocal sum.
