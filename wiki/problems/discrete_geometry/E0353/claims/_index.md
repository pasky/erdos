# problems/discrete_geometry/E0353/claims

[[problems/discrete_geometry/E0353/_index|..]]

[[problems/discrete_geometry/E0353/claims/2024_12_16_kovac_predojevic|2024_12_16_kovac_predojevic]]: Kovač and Predojević prove that every measurable planar set of infinite
measure contains the vertices of a cyclic quadrilateral of area $1$. They also
show that some planar set of infinite measure contains no convex polygon with
congruent sides and area $1$.

[[problems/discrete_geometry/E0353/claims/2025_01_03_koizumi|2025_01_03_koizumi]]: Koizumi proves that every measurable planar set of infinite measure contains
the vertices of an isosceles trapezoid of area $1$. Every unbounded measurable
planar set of positive measure contains those of an isosceles triangle and of
a right triangle of area $1$.
