# problems/extremal_graph_theory/E0073/claims

[[problems/extremal_graph_theory/E0073/claims/1999_02_01_reed|1999_02_01_reed]]: Reed proves that for every $k$ there is $f(k)$ such that if every subgraph $H$
of a graph has an independent set of at least $(|H|-k)/2$ vertices, then
deleting at most $f(k)$ vertices makes the graph bipartite. This answers
Problem 73.
