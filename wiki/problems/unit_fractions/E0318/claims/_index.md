# problems/unit_fractions/E0318/claims

[[problems/unit_fractions/E0318/_index|..]]

[[problems/unit_fractions/E0318/claims/1975_01_01_erdos_straus|1975_01_01_erdos_straus]]: Erdős and Straus's 1975 solution to Problem 387 of Nieuw Archief: for every
non-constant sign sequence on the positive integers, some finite set of the
signed reciprocals sums to zero. This is the case $A=\mathbb N$ of the first
question.

[[problems/unit_fractions/E0318/claims/1975_01_01_sattler|1975_01_01_sattler]]: Sattler's 1975 solution to Problem 387 of Nieuw Archief: for every
non-constant sign sequence on the denominators $2i+1$, some finite set of the
signed reciprocals sums to zero. This is the case of the odd numbers in the
first question.

[[problems/unit_fractions/E0318/claims/1982_01_01_erdos|1982_01_01_erdos]]: Erdős's observation, published in Sattler's 1982 paper on squarefree numbers,
that an infinite set with exactly one even element has a sign pattern with no
zero-sum of signed reciprocals. This answers the second question no.

[[problems/unit_fractions/E0318/claims/1982_01_01_sattler|1982_01_01_sattler]]: Sattler's 1982 theorem that every infinite arithmetic progression has property
$P_1$: for each non-constant sign assignment on it, some finite subset has
signed reciprocals summing to zero. This answers the first question yes.

[[problems/unit_fractions/E0318/claims/2026_02_01_larsen|2026_02_01_larsen]]: Larsen's Theorem 6: for every partition of the perfect squares greater than
$1$ into two parts, some finite subset of one part has the same reciprocal sum
as some finite subset of the other. So the squares other than $1$ have
property $P_1$, and the third question is answered yes.

[[problems/unit_fractions/E0318/claims/2026_08_16_alexeev|2026_08_16_alexeev]]: A Lean development in Alexeev's repository, with Codex and GPT-5.6 Sol as its
formal authors, proves that every infinite arithmetic progression has property
$P_1$, the first question. The claim names no published proof as its source.
