# problems/additive_bases/E0221/claims

[[problems/additive_bases/E0221/_index|..]]

[[problems/additive_bases/E0221/claims/1972_06_01_ruzsa|1972_06_01_ruzsa]]: Ruzsa constructed a set $A$ with
$\lvert A\cap\{1,\ldots,N\}\rvert\ll N/\log N$ such that every large integer
is $2^k+a$ with $k\ge0$ and $a\in A$. This answers Problem 221 yes.

[[problems/additive_bases/E0221/claims/2001_04_01_ruzsa|2001_04_01_ruzsa]]: Ruzsa constructed a set $A$ with
$\lvert A\cap\{1,\ldots,N\}\rvert\sim N/\log_2N$ such that every large integer
is $2^k+a$ with $k\ge0$ and $a\in A$. This is the best possible count for
Problem 221.
