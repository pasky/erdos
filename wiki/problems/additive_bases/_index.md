# Additive Bases and Sidon Sets

[[problems/_index|..]]

[[problems/additive_bases/E0009/_index|E0009/]]: Asks whether the odd integers
not of the form $p+2^k+2^l$, with $p$ prime and $k,l\geq 0$, have positive upper
density; open.

[[problems/additive_bases/E0010/_index|E0010/]]: Asks whether some fixed $k$
makes every large integer the sum of a prime and at most $k$ powers of 2. It is
open, but three powers are known not to suffice: infinitely many even integers
are not a prime plus at most three powers of 2.

[[problems/additive_bases/E0011/_index|E0011/]]: Asks whether every large odd
integer is the sum of a squarefree number and a power of 2; open.

[[problems/additive_bases/E0014/_index|E0014/]]: Asks whether, for every $A$,
the integers up to $N$ lacking a unique representation as a sum of two elements
of $A$ number $\gg_\epsilon N^{1/2-\epsilon}$, and whether they can number
$o(N^{1/2})$. The answers are yes and no, by two Lean proofs the bounty site
Conjectures.io accepted.

[[problems/additive_bases/E0016/_index|E0016/]]: Asks whether the odd integers
not of the form $2^k+p$ are the union of an infinite arithmetic progression and
a set of density $0$; the answer is no.

[[problems/additive_bases/E0028/_index|E0028/]]: Asks whether, when $A+A$
contains all but finitely many integers, some integers must have arbitrarily
many representations as a sum of two elements of $A$; open.

[[problems/additive_bases/E0029/_index|E0029/]]: Asks whether there is an
explicit set $A$ with $A+A=\mathbb{N}$ whose number of representations $1_A\ast
1_A(n)$ is $o(n^\epsilon)$ for every $\epsilon>0$; answered yes.

[[problems/additive_bases/E0030/_index|E0030/]]: Asks whether the largest Sidon
set in $\{1,\ldots,N\}$ has size $N^{1/2}+O_\epsilon(N^\epsilon)$ for every
$\epsilon>0$; open.

[[problems/additive_bases/E0031/_index|E0031/]]: Asks whether every infinite set
$A\subset\mathbb{N}$ has a set $B$ of density $0$ such that $A+B$ contains all
but finitely many integers; proved.

[[problems/additive_bases/E0032/_index|E0032/]]: Asks how sparse a set $A$ can
be if every large integer is a prime plus an element of $A$, measured against
$(\log N)^2$; open.

[[problems/additive_bases/E0033/_index|E0033/]]: Asks how sparse a set $A$ can
be if every large integer is a square plus an element of $A$, measured against
$N^{1/2}$; open.

[[problems/additive_bases/E0035/_index|E0035/]]: Asks whether adding an additive
basis of order $k$ to a set of Schnirelmann density $\alpha$ raises the density
by at least $\alpha(1-\alpha)/k$; proved.

[[problems/additive_bases/E0039/_index|E0039/]]: Asks whether some infinite
Sidon set has $\gg_\epsilon N^{1/2-\epsilon}$ elements up to $N$ for every
$\epsilon>0$; open.

[[problems/additive_bases/E0040/_index|E0040/]]: Asks for which functions
$g(N)\to\infty$ a set with $\gg N^{1/2}/g(N)$ elements up to $N$ must have
integers with arbitrarily many representations as a sum of two elements; open.

[[problems/additive_bases/E0041/_index|E0041/]]: Asks whether an infinite set
$A$ whose triple sums $a+b+c$ are all distinct must have $\liminf \lvert
A\cap\{1,\ldots,N\}\rvert/N^{1/3}=0$; open.

[[problems/additive_bases/E0042/_index|E0042/]]: Asks whether, for $N$ large in
terms of $M$, every Sidon set $A\subset\{1,\ldots,N\}$ has a Sidon set
$B\subset\{1,\ldots,N\}$ of size $M$ with $(A-A)\cap(B-B)=\{0\}$; answered yes
for non-empty $A$.

[[problems/additive_bases/E0043/_index|E0043/]]: Asks whether two Sidon sets in
$\{1,\ldots,N\}$ whose difference sets meet only at $0$ together have at most as
many pairs as a largest Sidon set plus a constant, and a constant fraction fewer
when they have equal size; both answers are no.

[[problems/additive_bases/E0044/_index|E0044/]]: Asks whether, for any
$\epsilon>0$, every Sidon set $A\subset\{1,\ldots,N\}$ extends by elements above
$N$ to a Sidon set of size at least $(1-\epsilon)M^{1/2}$ in some
$\{1,\ldots,M\}$; open.

[[problems/additive_bases/E0066/_index|E0066/]]: Asks whether some
$A\subseteq\mathbb{N}$ has its number of representations $1_A\ast 1_A(n)$,
divided by $\log n$, tending to a nonzero limit; open.

[[problems/additive_bases/E0152/_index|E0152/]]: Asks whether, for every $M$,
each sufficiently large finite Sidon set $A$ has at least $M$ sums $a\in A+A$
with $a-1,a+1\notin A+A$; proved.

[[problems/additive_bases/E0153/_index|E0153/]]: Asks whether, for a finite
Sidon set $A$, the mean squared gap between consecutive elements of $A+A$ tends
to infinity as $\lvert A\rvert\to\infty$; open.

[[problems/additive_bases/E0154/_index|E0154/]]: Asks whether, for a Sidon set
$A\subset\{1,\ldots,N\}$ with $\lvert A\rvert\sim N^{1/2}$, the sumset $A+A$ is
evenly spread over small moduli, for instance half even and half odd; proved.

[[problems/additive_bases/E0155/_index|E0155/]]: Asks whether the largest size
$F(N)$ of a Sidon subset of $\{1,\ldots,N\}$ satisfies $F(N+k)\leq F(N)+1$ for
every fixed $k\geq 1$ and all large $N$; open.

[[problems/additive_bases/E0156/_index|E0156/]]: Asks whether $\{1,\ldots,N\}$
contains a maximal Sidon set of size $O(N^{1/3})$; open.

[[problems/additive_bases/E0157/_index|E0157/]]: Asks whether some infinite
Sidon set is an asymptotic basis of order $3$, so that every large integer is a
sum of three of its elements; proved.

[[problems/additive_bases/E0158/_index|E0158/]]: Asks whether every infinite
$A\subset\mathbb{N}$ in which each $n$ has at most two representations $a+b=n$
with $a\leq b$ must have $\liminf \lvert A\cap\{1,\ldots,N\}\rvert/N^{1/2}=0$;
open.

[[problems/additive_bases/E0221/_index|E0221/]]: Asks whether some set $A$ with
$\ll N/\log N$ elements up to $N$ makes every large integer of the form $2^k+a$
with $a\in A$; proved.

[[problems/additive_bases/E0241/_index|E0241/]]: Asks whether the largest subset
of $\{1,\ldots,N\}$ whose triple sums $a+b+c$ are all distinct has size
asymptotic to $N^{1/3}$; open.

[[problems/additive_bases/E0326/_index|E0326/]]: Asks whether some minimal basis
of order $2$, with elements $a_1<a_2<\cdots$, has $a_k/k^2$ tending to a nonzero
constant; a 2026 proof claim is pending. Erdős first asked this for any basis of
order $2$, which Cassels answered yes.

[[problems/additive_bases/E0330/_index|E0330/]]: Asks whether some minimal basis
of positive density has, for each element $n$, a positive upper density of
integers that cannot be represented without $n$; proved.

[[problems/additive_bases/E0333/_index|E0333/]]: Asks whether every set
$A\subseteq\mathbb{N}$ of density zero lies in $B+B$ for some set $B$ with
$\lvert B\cap\{1,\ldots,N\}\rvert=o(N^{1/2})$; disproved.

[[problems/additive_bases/E0336/_index|E0336/]]: Asks for $\lim_r h(r)/r^2$,
where $h(r)$ is the largest finite exact order of an additive basis of order
$r$; a pending claim answers it.

[[problems/additive_bases/E0337/_index|E0337/]]: Asks whether every additive
basis $A$ of density zero has $\lvert (A+A)\cap\{1,\ldots,N\}\rvert/\lvert
A\cap\{1,\ldots,N\}\rvert\to\infty$; disproved.

[[problems/additive_bases/E0338/_index|E0338/]]: Asks when a basis has a
restricted order, defined with distinct summands only, and whether that order is
bounded in terms of the ordinary order; open.

[[problems/additive_bases/E0339/_index|E0339/]]: Asks whether the integers that
are sums of exactly $r$ distinct elements of a basis of order $r$ must have
positive lower density; proved.

[[problems/additive_bases/E0340/_index|E0340/]]: Asks for the growth rate of the
greedy Sidon sequence, and whether its counting function is $\gg
N^{1/2-\epsilon}$ for every $\epsilon>0$; open.

[[problems/additive_bases/E0343/_index|E0343/]]: Asks, after Folkman, whether
there is an absolute constant $C$ such that every multiset of integers with
counting function at least $CN$ has subset sums containing an infinite
arithmetic progression. Szemerédi and Vu proved this, and Folkman's question for
every constant is open.

[[problems/additive_bases/E0344/_index|E0344/]]: Asks whether, for a
sufficiently large constant $c$, every set of integers with at least $cN^{1/2}$
elements up to $N$, for every $N$, has subset sums containing an infinite
arithmetic progression; proved.

[[problems/additive_bases/E0345/_index|E0345/]]: Asks whether infinitely many
$k$ make the completeness threshold of the $k$th powers larger than that of the
$(k+1)$th powers, $T(n^k)>T(n^{k+1})$; open.

[[problems/additive_bases/E0346/_index|E0346/]]: Asks whether a sequence that
stays complete after any finite deletion but never after an infinite one, with
$a_{n+1}/a_n\ge1+\epsilon$ for some $\epsilon>0$, must have
$a_{n+1}/a_n\to(1+\sqrt5)/2$; disproved.

[[problems/additive_bases/E0347/_index|E0347/]]: Asks whether some integer
sequence with $a_{n+1}/a_n\to2$ has subset sums of density $1$ even after any
finite set of terms is removed; proved.

[[problems/additive_bases/E0348/_index|E0348/]]: Asks for which $0\le m<n$ a
complete sequence can stay complete after removing any $m$ elements yet fail to
be complete after removing any $n$ elements; a pending claim answers it.

[[problems/additive_bases/E0349/_index|E0349/]]: Asks for which $t,\alpha>0$ the
sequence $\lfloor t\alpha^n\rfloor$ is complete, meaning that sums of distinct
terms give all large integers; open.

[[problems/additive_bases/E0351/_index|E0351/]]: Asks whether the numbers
$p(n)+1/n$, for $p\in\mathbb{Q}[x]$ with positive leading coefficient, stay
complete after any finite set is removed; proved.

[[problems/additive_bases/E0354/_index|E0354/]]: Asks whether $\lfloor
2^k\alpha\rfloor$ and $\lfloor 2^k\beta\rfloor$, for $\alpha,\beta>0$ with
$\alpha/\beta$ irrational, together form a complete sequence, and the same for a
base $\gamma\in(1,2)$. The first question is answered yes and the second has two
readings; open overall.

[[problems/additive_bases/E0358/_index|E0358/]]: Asks whether some infinite
sequence of integers writes every large $n$ as a sum of consecutive terms at
least twice, or in a number of ways $f(n)\to\infty$; proved.

[[problems/additive_bases/E0425/_index|E0425/]]: Asks for an estimate of the
largest subset of $\{1,\ldots,n\}$ with distinct pairwise products, and a bound
for sets whose products of $r$ increasing members are distinct; open.

[[problems/additive_bases/E0530/_index|E0530/]]: Asks for the order of
$\ell(N)$, the size of the largest Sidon subset, one with no non-trivial equal
pairwise sums, guaranteed inside every set of $N$ reals. The order is $N^{1/2}$,
and whether $\ell(N)\sim N^{1/2}$ is open.

[[problems/additive_bases/E0707/_index|E0707/]]: Asks whether every finite Sidon
set of integers can be extended to a perfect difference set modulo $p^2+p+1$ for
some prime $p$; disproved.

[[problems/additive_bases/E0757/_index|E0757/]]: Asks for the best constant $c$
such that $n$ reals whose every four-element subset $B$ has $\lvert
B-B\rvert\ge11$ contain a Sidon set of size $cn$; open.

[[problems/additive_bases/E0772/_index|E0772/]]: Asks whether
$H_k(n)/n^{1/2}\to\infty$, where $H_k(n)$ is the size of the largest Sidon set
guaranteed inside any $n$ integers in which no number has more than $k$
representations as a sum of two elements; proved.

[[problems/additive_bases/E0773/_index|E0773/]]: Asks for the size of the
largest Sidon subset of the squares $\{1,2^2,\ldots,N^2\}$, and whether it is
$N^{1-o(1)}$; open.

[[problems/additive_bases/E0840/_index|E0840/]]: Asks how fast the largest
quasi-Sidon subset of $\{1,\ldots,N\}$ grows, where $A$ is quasi-Sidon if
$\lvert A+A\rvert=(1+o(1))\binom{\lvert A\rvert}{2}$; open.

[[problems/additive_bases/E0861/_index|E0861/]]: Asks how the number of Sidon
subsets of $\{1,\ldots,N\}$ compares with $2^{f(N)}$, where $f(N)$ is the size
of the largest Sidon subset; solved.

[[problems/additive_bases/E0862/_index|E0862/]]: Asks whether the number of
maximal Sidon subsets of $\{1,\ldots,N\}$ is below $2^{o(N^{1/2})}$, and whether
it exceeds $2^{N^c}$ for some $c>0$; solved.

[[problems/additive_bases/E0863/_index|E0863/]]: Asks whether, for $r\ge2$, the
largest sets in $\{1,\ldots,N\}$ with at most $r$ representations of each sum,
and of each positive difference, have sizes $\sim c_rN^{1/2}$ and $\sim
c_r'N^{1/2}$ with $c_r\ne c_r'$, and whether $c_r'<c_r$; proved.

[[problems/additive_bases/E0864/_index|E0864/]]: Asks for an estimate of the
largest set $A\subseteq\{1,\ldots,N\}$ in which at most one number has more than
one representation as a sum of two members; open.

[[problems/additive_bases/E0868/_index|E0868/]]: Asks whether an additive basis
of order $2$ whose representation counts tend to infinity must contain a minimal
such basis; disproved.

[[problems/additive_bases/E0869/_index|E0869/]]: Asks whether the union of two
disjoint additive bases of order $2$ must contain a minimal additive basis of
order $2$; disproved.

[[problems/additive_bases/E0870/_index|E0870/]]: Asks whether, for $k\ge3$,
representation counts $r(n)\ge c\log n$ with a suitable constant $c$ force an
additive basis of order $k$ to contain a minimal one; a pending claim disproves
it.

[[problems/additive_bases/E0871/_index|E0871/]]: Asks whether an additive basis
$A$ of order $2$ with $1_A\ast 1_A(n)\to\infty$ can be split into two disjoint
additive bases of order $2$; disproved.

[[problems/additive_bases/E0880/_index|E0880/]]: Asks whether the integers that
are sums of $k$ or fewer distinct elements of an additive basis of order $k$
have bounded gaps; disproved for every $k\ge3$.

[[problems/additive_bases/E0881/_index|E0881/]]: Asks whether every minimal
additive basis $A$ of order $k$, one that stops being a basis of order $k$ when
any infinite subset is removed, has an infinite $B\subset A$ with $A\setminus B$
a basis of order $k+1$; a pending claim answers no.

[[problems/additive_bases/E1145/_index|E1145/]]: Asks whether $\limsup 1_A\ast
1_B(n)=\infty$ whenever $A=\{a_1<a_2<\cdots\}$ and $B=\{b_1<b_2<\cdots\}$ are
sets of positive integers with $a_n/b_n\to1$ and $A+B$ contains all large
integers; open.

[[problems/additive_bases/E1147/_index|E1147/]]: Asks whether, for irrational
$\alpha>0$, the set of $n$ such that $\alpha n^2$ lies within $1/\log n$ of an
integer is an additive basis of order $2$; disproved.

[[problems/additive_bases/E1191/_index|E1191/]]: Asks whether every infinite
Sidon set $A$ has $\lvert A\cap[1,x]\rvert=o\bigl((x/\log x)^{1/2}\bigr)$ along
a subsequence, and whether some infinite Sidon set has $\lvert
A\cap[1,x]\rvert\gg x^{1/2}/(\log x)^c$ for some $c>0$; open.

[[problems/additive_bases/E1192/_index|E1192/]]: Asks whether, for every
$r\ge2$, some basis $A$ of order $r$ has $\sum_{n\le x}f_r(n)^2\ll x$, where
$f_r(n)$ counts the representations of $n$ as a sum of $r$ elements of $A$;
open.

[[problems/additive_bases/E1194/_index|E1194/]]: Asks how fast $a_n/n$ must grow
when $A\subset\mathbb{N}$ is a set in which every integer $n\ge1$ is uniquely a
difference $a_n-b_n$ of two elements of $A$; open.

[[problems/additive_bases/E1206/_index|E1206/]]: Asks whether
$\{1,2^3,\ldots,N^3\}$ contains a Sidon set of size $\gg N$, and whether the
cubes of some set of positive density form a Sidon set; open. A Sidon set has
all pairwise sums distinct.

integer.
