# problems/ramsey_theory/E0559/claims

[[problems/ramsey_theory/E0559/_index|..]]

[[problems/ramsey_theory/E0559/claims/1983_03_01_beck|1983_03_01_beck]]: Beck's refereed 1983 theorem (J. Graph Theory) shows that the size Ramsey
number of the path is below $900n$ for large $n$, which is the statement for
paths. The paper is not held, and the bound rests on three printed
attestations.

[[problems/ramsey_theory/E0559/claims/1987_03_01_friedman_pippenger|1987_03_01_friedman_pippenger]]: In a refereed paper (Combinatorica 1987), Friedman and Pippenger show that for
fixed $d$ there is a graph with $O(n)$ edges in which every half of the edges
contains every $n$-vertex tree of maximum degree $d$. So such trees have
linear size Ramsey number.

[[problems/ramsey_theory/E0559/claims/1995_09_01_haxell_kohayakawa_luczak|1995_09_01_haxell_kohayakawa_luczak]]: Corollary 11 of Haxell, Kohayakawa and Łuczak (1995), a refereed result, shows
that the induced size Ramsey number of the cycle is linear in its length for
every fixed number of colors. So cycles have linear size Ramsey number.

[[problems/ramsey_theory/E0559/claims/2000_02_01_rodl_szemeredi|2000_02_01_rodl_szemeredi]]: Theorem 1 of Rödl and Szemerédi (Combinatorica 2000) gives, for large $n$, an
$n$-vertex graph of maximum degree $3$ whose size Ramsey number is at least
$cn(\log_2n)^\alpha$ with $c,\alpha>0$. So the statement fails at $d=3$.

[[problems/ramsey_theory/E0559/claims/2017_01_25_javadi_khoeini_omidi_pokrovskiy|2017_01_25_javadi_khoeini_omidi_pokrovskiy]]: Theorem 1.1 of Javadi, Khoeini, Omidi and Pokrovskiy (Combin. Probab. Comput.
2019) gives an explicit linear bound on the size Ramsey number of long cycles
without the regularity lemma. It is a second, refereed proof for cycles.

[[problems/ramsey_theory/E0559/claims/2022_10_11_tikhomirov|2022_10_11_tikhomirov]]: Theorem 1.1 of Tikhomirov (Combinatorica 2024; arXiv October 2022) gives, for
every $n$, an $n$-vertex graph of maximum degree at most three with size
Ramsey number at least $cn\exp(c\sqrt{\log n})$. This is a second disproof at
$d=3$.
