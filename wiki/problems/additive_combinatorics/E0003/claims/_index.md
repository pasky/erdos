# problems/additive_combinatorics/E0003/claims

[[problems/additive_combinatorics/E0003/_index|..]]

[[problems/additive_combinatorics/E0003/claims/2004_04_08_green_tao|2004_04_08_green_tao]]: Theorem 1.1 of Green and Tao (Ann. of Math. 2008) states that the primes
contain arbitrarily long arithmetic progressions. This is the conclusion of
Problem 3 for the set of primes, accepted on the refereed publication.

[[problems/additive_combinatorics/E0003/claims/2020_07_07_bloom_sisask|2020_07_07_bloom_sisask]]: Corollary 1.2 of Bloom and Sisask's 2020 preprint states that a set of natural
numbers with divergent reciprocal sum contains infinitely many three-term
arithmetic progressions. This is the case $k=3$ of the problem, and it is
claimed, with no journal version.

[[problems/additive_combinatorics/E0003/claims/2026_09_23_openai|2026_09_23_openai]]: Corollary 1.2 of the OpenAI release manuscript of 23 September 2026 answers
Problem 3 yes. Its Lean declaration, pinned by a comparator challenge, was
built and audited by this corpus, so the claim is accepted.
