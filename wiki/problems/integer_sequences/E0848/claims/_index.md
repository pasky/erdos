# problems/integer_sequences/E0848/claims

[[problems/integer_sequences/E0848/_index|..]]

[[problems/integer_sequences/E0848/claims/2025_10_19_sawhney|2025_10_19_sawhney]]: Sawhney's note proves that for all large $N$ no set in $\{1,\ldots,N\}$ in
which $ab+1$ is never squarefree has more members than the class $7\bmod25$,
and adds a stability statement. The erdosproblems.com curator credits it, and
a finite check remains.

[[problems/integer_sequences/E0848/claims/2026_03_23_sothanaphan|2026_03_23_sothanaphan]]: Sothanaphan's note of 23 March 2026, produced with GPT-5.2 Thinking and
GPT-5.4 Thinking, claims that for every $N\ge2.64\cdot10^{17}$ the class
$7\bmod25$ attains the maximum, making Sawhney's threshold explicit. Nothing
in it is accepted.

[[problems/integer_sequences/E0848/claims/2026_07_28_pitchford|2026_07_28_pitchford]]: Ian Pitchford published a candidate computer-assisted proof on Zenodo on 28
July 2026, with OpenAI Codex as its reported author. It claims the maximum is
$\lfloor(N+18)/25\rfloor$ for every $N$, using certificates and envelopes up
to $2.64\cdot10^{17}$.

[[problems/integer_sequences/E0848/claims/2026_07_30_li|2026_07_30_li]]: Li's full proof claim was released on 30 July 2026, submitted to
erdosproblems.com on 16 August 2026, and produced with OpenAI ChatGPT 5.5 and
5.6. It asserts that the largest set in $\{1,\ldots,N\}$ in which $ab+1$ is
never squarefree has exactly $\lfloor(N+18)/25\rfloor$ members.
