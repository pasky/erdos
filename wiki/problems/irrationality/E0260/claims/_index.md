# problems/irrationality/E0260/claims

[[problems/irrationality/E0260/_index|..]]

[[problems/irrationality/E0260/claims/1981_05_11_erdos|1981_05_11_erdos]]: Erdős's 1981 note in the Comptes Rendus proves that $\sum a_n/2^{a_n}$ is
irrational for every increasing integer sequence whose consecutive gaps tend
to infinity. These sequences form a class of instances of the question.

[[problems/irrationality/E0260/claims/2026_06_23_wang_grau_ribas|2026_06_23_wang_grau_ribas]]: Wang and Grau Ribas's 2026 preprint (later versions by Wang alone) claims that
an infinite set $S$ with $\sum_{n\in S}n/2^n$ rational has positive density on
every large dyadic block, so that Problem 260's series is irrational.
